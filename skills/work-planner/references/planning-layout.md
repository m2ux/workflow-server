# Planning Layout

A planning record is the folder [Add Planning Record](commands.md#add-planning-record) creates. README.md is the one file it must hold. The process adds any further files it needs.

```text
./
├── README.md
└── …
```

## Prerequisites

Command operations use the [command conventions](commands.md#conventions), read before the first spec.

## README.md

The entry point of the record. Its shape is the [planning README](planning-readme.md).

## Further files

Any file beyond README.md. The process chooses the names. Each one is a row in the README's Internal Links.
