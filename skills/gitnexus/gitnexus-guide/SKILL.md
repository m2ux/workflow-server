# GitNexus Guide

Quick reference for all GitNexus MCP tools, resources and the knowledge graph schema, and the route from a task to the GitNexus skill that answers it. Each request is answered in [Operations](references/operations.md):

- [Start a Task](references/operations.md#start-a-task): any task involving code understanding, debugging, impact analysis or refactoring
- [Skills](references/operations.md#skills): the GitNexus skill that answers each kind of task
- [Tools](references/operations.md#tools): what each MCP tool gives
- [Resources](references/operations.md#resources): the lightweight reads for navigation
- [Graph Schema](references/operations.md#graph-schema): the node and edge types a Cypher query matches

## Dependencies

- **GitNexus MCP server**  Serves the tools and the `gitnexus://` resources this guide describes.
