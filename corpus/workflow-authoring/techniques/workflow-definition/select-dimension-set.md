## Capability

The create-mode design dimensions, in the order the elicitation guide states.

## Outputs

### design_dimensions

The create set from [Mode Dimension Sets](../../resources/elicitation-guide.md#mode-dimension-sets), in that order, each entry the dimension's name.

## Protocol

### 1. Select the Dimension Set

- Take the create set, in its stated order, from [Mode Dimension Sets](../../resources/elicitation-guide.md#mode-dimension-sets). Do not restate or reorder the list here.
- Emit that set as `{design_dimensions}`.
