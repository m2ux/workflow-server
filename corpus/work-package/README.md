# Work package

Routines, techniques, and resources the work-package modes share. Each mode is a workflow under `workflows/`.

| Mode | Purpose |
| --- | --- |
| `workflows/legacy` | The combined run an operator can start |
| `workflows/implement` | Authoring through a public pull request |
| `workflows/review` | A posted review of an existing pull request |
| `workflows/remediate` | Remediation whose push reaches only a private remote |
