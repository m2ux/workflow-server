# Manage Artifacts

> Part of [techniques](../README.md)

Shared contract for a workflow's planning-folder artifacts — prefixing, organization, and output discipline.

The shared contract every operation here inherits is in [`TECHNIQUE.md`](TECHNIQUE.md); what each one contributes is below.

| Technique | Contributes |
|---|---|
| [`verify-artifact-links`](verify-artifact-links.md) | Link integrity across a planning folder, measured as a reader following the published links would experience it |
| [`write-artifact`](write-artifact.md) | Planning-folder artifact write keyed on bare filename — one numbered instance per logical artifact (find-or-update) |
