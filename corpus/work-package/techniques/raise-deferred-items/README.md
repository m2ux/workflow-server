# Raise Deferred Items

> Part of [techniques](../README.md)

Deferred-items register rows carried into the issue tracker.

The shared contract every operation here inherits is in [`TECHNIQUE.md`](TECHNIQUE.md); what each one contributes is below.

| Technique | Contributes |
|---|---|
| [`collect`](collect.md) | The deferred-items register read for rows that name no issue yet |
| [`record`](record.md) | A deferred-items register row naming the issue raised for it |
