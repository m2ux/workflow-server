# Raise Deferred Items

> Part of [techniques](../README.md)

Deferred-items register entries carried into the issue tracker.

The shared contract every technique here inherits is in [`TECHNIQUE.md`](TECHNIQUE.md); what each one contributes is below.

| Technique | Contributes |
|---|---|
| [`collect`](collect.md) | The deferred-items register read for entries that name no issue yet |
| [`record`](record.md) | A deferred-items register entry naming the issue raised for it |
