# Implementation Analysis

> Part of [techniques](../README.md)

Current-implementation effectiveness analysis — baseline metrics, gaps, and documented opportunities.

The shared contract every operation here inherits is in [`TECHNIQUE.md`](TECHNIQUE.md); what each one contributes is below.

| Technique | Contributes |
|---|---|
| [`analyze`](analyze.md) | Effectiveness, baseline metrics, and gaps of the current implementation against success criteria |
| [`document`](document.md) | Create the analysis-document artifact capturing the current state, baseline metrics, identified gaps, and improvement opportunities |
