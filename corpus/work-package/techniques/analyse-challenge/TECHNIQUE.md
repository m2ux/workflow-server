## Capability

Adversarial challenge of a concern set and the fold of its findings back into that set — the shared contract both operations work over.

## Inputs

### challenge_perspectives

List of adversarial perspectives (or lens names) for the challenge pass.

### concern_document

The document holding the concern set — the log or table this pass reads and updates.
