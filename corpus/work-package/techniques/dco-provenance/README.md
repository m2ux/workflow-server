# Dco Provenance

The shared contract every operation here inherits is in [`TECHNIQUE.md`](TECHNIQUE.md); what each one contributes is below.

| Technique | Contributes |
|---|---|
| [`append-task-row`](append-task-row.md) | Per-task row in `provenance-log.md` (canonical header on first write) |
| [`record-attestation`](record-attestation.md) | Human DCO attestation recorded once per work package in `provenance-log.md` |
