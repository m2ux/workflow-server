# Manage Registers

> Part of [techniques](../README.md)

Shared contract for the work package's two open-work registers — the single home each keeps for its class of outstanding item, one entry per item.

The shared contract every technique here inherits is in [`TECHNIQUE.md`](TECHNIQUE.md); what each one contributes is below.

| Technique | Contributes |
|---|---|
| [`append-deferred-item`](append-deferred-item.md) | The out-of-scope deferrals register, carrying one entry per item consciously placed beyond this work package |
| [`append-follow-up`](append-follow-up.md) | The in-task follow-ups register, carrying one entry per piece of work still owed inside this work package |
