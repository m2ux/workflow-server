# Validate Build

> Part of [techniques](../README.md)

Triage validation failures and aggregate cross-check results.

The shared contract every technique here inherits is in [`TECHNIQUE.md`](TECHNIQUE.md); what each one contributes is below.

| Technique | Contributes |
|---|---|
| [`analyze-failure`](analyze-failure.md) | Identify the root cause of a single failed validation check |
| [`apply-fix`](apply-fix.md) | Concrete fix for a failed validation check, ready for re-validation |
