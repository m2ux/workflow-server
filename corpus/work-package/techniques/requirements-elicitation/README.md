# Requirements Elicitation

> Part of [techniques](../README.md)

Discover and clarify requirements through structured sequential conversation.

The shared contract every technique here inherits is in [`TECHNIQUE.md`](TECHNIQUE.md); what each one contributes is below.

| Technique | Contributes |
|---|---|
| [`create-document`](create-document.md) | Create the requirements document artifact capturing elicited requirements, success criteria, scope boundaries, and assumptions |
| [`discuss`](discuss.md) | The baseline elicitation builds its questions on — the stakeholder discussion where one was held, and the recorded limitation where none was |
| [`elicit`](elicit.md) | Requirements, success criteria and scope boundaries elicited across the question domains, with the question-and-response record behind them |
| [`pose-question`](pose-question.md) | The next question for one elicitation domain, narrowed to what the record does not already answer |
| [`record-answer`](record-answer.md) | The elicitation record extended with one question and the answer given to it |
| [`select-domains`](select-domains.md) | The question domains this run elicits across, drawn from the reference and narrowed to what the stakeholder discussion left open |
