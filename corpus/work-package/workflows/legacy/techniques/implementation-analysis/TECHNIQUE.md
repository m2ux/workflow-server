## Capability

Current-implementation effectiveness analysis — baseline metrics and the gaps the change closes.

## Inputs

### component_name

Basename of the component the work package targets (e.g., midnight-node, midnight-ledger)

## Outputs

### analysis_document

Current implementation [analysis](../../resources/implementation-analysis.md#document-template) with baselines and the gaps they open



## Rules

### baselines-are-quantitative

Every baseline carries a value and the method that measured it, so a later comparison reproduces it.
