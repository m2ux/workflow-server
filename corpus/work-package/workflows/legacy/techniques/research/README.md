# Research

> Part of [techniques](../README.md)

Knowledge-base and external research synthesized against work-package requirements.

The shared contract every technique here inherits is in [`TECHNIQUE.md`](TECHNIQUE.md); what each one contributes is below.

| Technique | Contributes |
|---|---|
| [`document`](document.md) | Create the research artifact capturing the synthesized findings, applicable patterns, and risks |
| [`reconcile`](reconcile.md) | Research-reconcilable candidates closed until only irreconcilable residue remains |
| [`research`](research.md) | Best practices, patterns, and resources gathered from the knowledge base and the web |
| [`synthesize`](synthesize.md) | Synthesize the knowledge base and web findings against the work package requirements, mapping applicable patterns to specific needs |
| [`triage`](triage.md) | Open research candidates classified as reconcilable-by-research or irreconcilable for the reconcile loop |
