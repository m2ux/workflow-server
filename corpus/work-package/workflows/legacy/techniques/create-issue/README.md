# Create Issue

> Part of [techniques](../README.md)

Shared contract for raising a tracker issue: what the issue is about, what kind of change it records, and the identity the run carries forward once it exists.

The shared contract every technique here inherits is in [`TECHNIQUE.md`](TECHNIQUE.md); what each one contributes is below.

| Technique | Contributes |
|---|---|
| [`create-github`](create-github.md) | A GitHub issue raised for the work package, labelled for the kind of change it records and verified to exist |
| [`create-jira`](create-jira.md) | A Jira issue raised for the work package in its project, typed for the kind of change it records |
