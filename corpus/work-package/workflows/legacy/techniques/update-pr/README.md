# Update Pr

> Part of [techniques](../README.md)

PR finalization for review — body update and ready mark, or consolidated review-mode commentary.

The shared contract every technique here inherits is in [`TECHNIQUE.md`](TECHNIQUE.md); what each one contributes is below.

| Technique | Contributes |
|---|---|
| [`create-pr`](create-pr.md) | Draft PR linked to the issue and assigned to the current GitHub user |
| [`mark-ready`](mark-ready.md) | Mark the PR ready for review once its description is finalized |
| [`post-review-comment`](post-review-comment.md) | Confirmed consolidated review summary posted verbatim to the PR as a pull-request review |
| [`render`](render.md) | PR description body from the selected template, sourced from planning artifacts |
| [`verify-body`](verify-body.md) | PR-body-conformance verdict for the rendered PR description (conforms flag and findings) |
