# Resources

Resources a work-package mode binds from this library. Each one is fill and consult: a template, a vocabulary, criteria, or policy. A section citation returns that section.

| Resource | What it holds |
| --- | --- |
| `plan-guide` | Plan template and the fill rules for its sections |
| `findings-report` | Shared finding layout, fields, and severity vocabulary |
| `close-out-guide` | Close-out template, with the retrospective as one section |
| `adr-guide` | Architecture decision record template |
| `requirements-elicitation` | Question-domain vocabulary and the elicitation document template |
| `design-framework` | Problem-classification vocabulary and the design-philosophy template |
| `assumptions-review` | Assumption probe and classification vocabulary, and the log template |
| `assumption-reconciliation` | Resolvability vocabulary for an assumption |
| `review-mode` | Review-comment template and the category vocabulary |
| `strategic-review` | Minimality criteria and the strategic-review template |
| `test-suite-review` | Test-review criteria and the report template |
| `rust-substrate-code-review` | Code-review criteria and the report template |
| `manual-diff-review` | Diff-block rationale vocabulary and the report template |
