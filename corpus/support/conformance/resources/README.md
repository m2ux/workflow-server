# Conformance Resources

> Part of the [conformance library](../README.md)

One guide, shared by every specimen that holds a library run to a positive and a negative case.

| Resource ID | Title | Purpose |
|-------------|-------|---------|
| `case-report` | Case Report | Creation guide for a case report — template and the rules governing what each row may claim about one run under its bindings, and which graph answered it |

A specimen names the report it persists in its own `resources/README.md` map and points the row here, so the filename stays the specimen's and the shape stays shared.
