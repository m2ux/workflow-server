# Conformance

The shape a specimen's evidence takes when it holds one library run to two cases: a positive case the run measures, and a negative case where the run takes the fallback it promises.

This is a **library namespace** holding one resource and no operation. It declares no `workflow.yaml` and takes no place in any graph. A specimen under `corpus/specimens/` refers to a run, binds it twice, and reports both bindings against the [case report](resources/case-report.md) guide here, so twenty specimens share one report shape and one set of rules about what a row may claim.
