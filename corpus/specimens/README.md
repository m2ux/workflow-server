# Specimen workflows

A specimen is a worked example of a form. An author copies from it when creating a workflow that needs that form, and a test drives it so the form stays loadable and observable. Specimens are workflows: they have a definition, activities and techniques, and discovery lists them by directory name.

They sit here, under `corpus/`, so they travel with the other definitions. This folder is a grouping — it organises the tree and names nothing of its own. Each child directory that holds a `workflow.yaml` is a workflow; open the directory for what it currently holds.
