# Contract Join Case Report

## Template

```markdown
# Work Package Contract Join Cases

| Case | Kind | Passed | Exit |
|---|---|---|---|

```

## Rules

### a-row-names-the-exit-the-join-took

Each row records the case that was walked, whether the suite passed, and the exit the join took. A row that describes the intended exit instead of the exit the walk took has reported the case design as the result.
