# Work Package Contract Join Conformance

A specimen of the implementation join's contract-test run: merge and run against the implementation, then disposition — pass, return to implementer, or dispute as a contract ambiguity.

| Activity | Role |
|---|---|
| `take-case` | binds pass, then rework, then dispute |
| `prepare-join` | seeds hoist state and the case's pass/fail outcome |
| `implementation-join` | merge stub, run stub, disposition and ambiguity gates |
| `record-case` / `report-cases` | case report |
