# GitNexus Restructure Surface Conformance

A specimen of one form: one library run held to a positive and a negative case, so the measurement and the promised fallback are evidenced side by side.

The run is `gitnexus::restructure-surface`, which takes the two measurements a symbol's restructuring rests on — its callers, callees and flow membership, and what depends on it at depth with a risk level. The positive case names a symbol the graph holds, so the context answer resolves its connections and the impact answer rates its dependents. The negative case names a symbol no graph holds, so the context answer resolves nothing and the impact answer withholds its rating — which is the fallback the run promises for a symbol outside the graph, and which the report names as such rather than as a symbol nothing reaches: both reports place the symbol outside the graph, and the run's own notes send the reader to grep.

What the walk evidences is the reference under two bindings: the same run resolves under `gitnexus::restructure-surface` twice, its steps splice into each activity under that activity's prefix, and its two outputs land under the four names the reference sites bind. The closing activity reports both against the shared [case report](/conformance/resources/case-report.md) guide.
