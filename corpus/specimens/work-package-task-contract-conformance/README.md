# Work Package Task Contract Conformance

A specimen of the plan's Contract rule: each implementation task carries Signatures, Behaviours, Error cases and Acceptance.

| Activity | Role |
|---|---|
| `take-case` | binds the complete-contract case, then the missing-field case |
| `write-plan` | writes a one-task plan under the case's Contract shape |
| `check-contracts` | verifies every task's Contract carries all four fields |
| `record-case` / `report-cases` | case report |

The complete case's check holds. The missing-field case's check fails and the report records the absent field.
