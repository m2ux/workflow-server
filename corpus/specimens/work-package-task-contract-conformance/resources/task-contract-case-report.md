# Task Contract Case Report

## Template

```markdown
# Work Package Task Contract Cases

| Case | Contract complete | Check held | Missing fields |
|---|---|---|---|
| 1 | yes/no | yes/no | field names or — |
| 2 | yes/no | yes/no | field names or — |
```

## Rules

### a-row-names-the-check-the-walk-ran

Each row records whether the task's Contract was complete, whether the check held, and which fields were missing. A row that lists the fields the case was built to omit, rather than the fields the check reported, has reported the fixture as the result.
