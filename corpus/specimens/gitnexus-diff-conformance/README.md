# GitNexus Diff Conformance

A specimen of one form: a workflow that holds no operations of its own and reaches five runs declared in a library namespace.

Each of the five reads a diff and narrows it — the coverage map that iterates the changed symbols one at a time, the scope check and the API enumeration that each chain two operations, the orphan scan that carries a literal graph query, and the risk assessment that reaches three operations before its judgement. Between them they cover every body shape a run takes over a diff: a chain, an iteration, a literal argument, and a judgement fed by more than one measurement.

What the walk evidences is the reference, not the measuring. A run declared in a library resolves under `gitnexus::<name>`, its steps splice into the referring activity carrying that activity's prefix, and its declared outputs land in this workflow's variable bag under the names the reference site binds. The closing activity states what each landed, so a run that materialised and measured nothing reads differently from one that never materialised.

The graph answers are whatever the host checkout holds. Point it at an indexed tree and the runs measure it; point it at an unindexed one and each run's own fallback note governs.

| Activity | Refers to |
|---|---|
| `measure-diff` | `diff-coverage-map`, `scope-discipline-check` |
| `scan-surface` | `orphan-scan`, `public-api-enum` |
| `weigh-risk` | `change-risk-assessment` |
| `report-conformance` | nothing — states what the three before it landed |
