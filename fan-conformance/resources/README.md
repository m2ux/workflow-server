## Why there is only one

The run's product is evidence about the routing: which slots were filled, by which designator, over which interval. The surveys the branches perform exist so the branches have real work to do, and their findings are summarised in a paragraph each rather than persisted — a second artifact would make the surveys look like the point.

The notes the isolated writers commit are not that second artifact. Each is a commit on a branch of its own, and what the report carries is the branch and whether it merged — the evidence that the writers were isolated, rather than the notes themselves.
