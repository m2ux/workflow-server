## Problem

Configuration from a different revision can produce a verdict about rules the evaluated change never contained. Missing configuration can also make a skipped check look successful.

## Proposal

- **Source identity.**
  Consume the source-aware reader from W06. Report absent, empty or unreadable configuration with repository, commit, path and the checks left unevaluated. Return an unresolved result rather than a passing check. Do not derive names from branch naming, another revision or project defaults.
- **Verification cases.**
  Use divergent subject and long-lived values, identical commits invoked from different worktrees, dirty working files, absent and empty declarations, unreadable revisions, and configuration present only at another revision. Assert both selected values and explicit unevaluable results.
