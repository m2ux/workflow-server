# Context Through Links

> Authoring preference · Created 2026-11-06

## Executive Summary

Work Planner discovers context through its ordinary in-text links and their selected boundaries. Remove every Prerequisites section from the installed skill, its layout declarations and rules requiring those lists or automatic prerequisite loading. Preserve actual task/delivery dependencies, execution gates, explicit whole-document instructions and contextual links.

The inventory finds 43 sections. Every listed target file also has a link elsewhere in its document. Remove the duplicate inventories; a section does not acquire sibling context through a deleted list. Keep necessary common context linked where selected work uses it. Retire the inventory-equality consumer test, retain meaningful link/contract/checkout/script coverage, and keep the generic shared checker available to other skills whose declarations use different layouts.

Run installed checks and affected suites. Exercise Standup, Understand and Revise through fresh independent readers with local captured inputs and authority limits; repeat affected scenarios and distinguish actual context retrieval from structural checks. Reconcile active future planning guidance where it would reinstate prerequisite inventories. Commit/push source and evidence on their existing worktree branches and retain the draft PR.
