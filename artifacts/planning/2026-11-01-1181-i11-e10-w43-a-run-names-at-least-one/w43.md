**Component:** `workspace:skills/scripts/check_skill_files.py`

## Overview

W43 has the shared skill check refuse a run that names no skill, so a check over an empty skill list fails rather than reads as clean.

## Problem

The [agent review of #1589](https://github.com/m2ux/workflow-server/blob/engineering/artifacts/planning/2026-11-01-1181-i11-e10-epic-review/review-1589-6b7afb23.json) at `6b7afb230` found that the check accepts a run naming no skill: `python3 skills/scripts/check_skill_files.py` prints `0 files checked, 0 findings` and exits 0. Its `roots` argument takes any number of folders, which served only the retired Verify Skills workflow passing over a tree holding no skill.

## Proposal

The check's `roots` argument takes one folder or more, as `workspace`'s does, so argparse refuses a run naming none with exit 2. The `--compare` form names its roots the same way.
