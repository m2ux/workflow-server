## Overview

W03 shows a Codex session acting on the workspace command policy, so that a registration the runtime discovers is known to reach the tool calls a session issues.

## Problem

The runtime diagnostic reports both hooks enabled and reports each as awaiting its trust review. Codex skips an untrusted hook, so discovery alone shows nothing about dispatch. The adapter suites feed the adapter a payload and read its answer; they show it decides correctly when called and establish nothing about whether the runtime calls it. An operation held for confirmation receives no automatic grant, so what a person sees depends on Codex's native approval settings rather than on the adapter alone.

## Proposal

A session opened in the rendered workspace, after deployment has registered the marketplace, installed the plugin and written the configuration, so the registrations it loads are the generated ones. Trust is granted through `/hooks` and the inventory recorded as the client shows it, before any tool call.

- One tool call per outcome: a command the policy denies, a command it grants, and an operation it holds for confirmation.
- Each fixture is harmless if it runs, because a session that fails to enforce will run it.
- The observed outcomes are read from this session alone. No outcome from Claude Code or Cursor is carried into this record.
- Only Codex delivers this task. The record carries the runtime identity Codex reports, which the harness identity check compares with the declared harness, so a session in another harness stops rather than writing this record.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Read the runtime's trust model and what a client shows for a discovered, untrusted registration |
| Plan | Choose one harmless fixture per outcome, and the record each observation lands in |
| Implementation | Deploy, open the session, review and trust both registrations through `/hooks` |
| Review | Compare each observed outcome with the decision the shared evaluator returns for the same command |
| Test | The session transcript for each fixture, and the client's hook inventory after the trust review |
