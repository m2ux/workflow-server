## Overview

Prism's container input `target_content` is optional. A step that binds an operation which never reads it no longer owes a required value the run does not hold.

## Problem

- **4 steps owe a value nothing supplies.**
  [`target_content`](https://github.com/m2ux/workflow-server/blob/c6774bff79af0e118b3de3532307c7ad40cd5d66/corpus/prism/techniques/TECHNIQUE.md#L12-L14) is required on prism's container. `plan-analysis`, `emit-run-manifest`, `link-report-references` and `generate-report` never read it, and the run holds no variable or earlier output of that name.

## Proposal

- **The scene.**
  The content under analysis reaches the lens passes through each step's binding. The mode, delivery and report activities bind operations that work on what those passes produced.
- **The home.**
  The operations that read the content share only the root container, so the input stays there and is optional. A step that reads it binds the value; a step that does not leaves it absent.
