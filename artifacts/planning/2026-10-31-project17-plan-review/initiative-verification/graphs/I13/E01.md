## Overview

This epic gives every required input a technique container hands its operations a source at each step that binds them, and adds the guard that keeps it so. The [inherited-input-never-spent](https://github.com/m2ux/workflow-server/blob/6fcee6ab/corpus/canon/resources/anti-patterns.md#L2429-L2441) entry names the defect: a container's required input that an operation never reads, bound where nothing holds it.

## Problem

- **125 steps owe a value nothing supplies.**
  The [entry's sweep](https://github.com/m2ux/workflow-server/blob/engineering/artifacts/planning/2026-10-05-706-unspent-inputs/sites.md) finds them in workflow-design (49), workflow-authoring (22), cicd-pipeline-security-audit (20), the github, atlassian and git libraries (16), work-package (14) and prism (4).
- **Library contracts require inputs most of their operations ignore.**
  github's [`target_repo`](https://github.com/m2ux/workflow-server/blob/bb38d574/corpus/support/github/techniques/TECHNIQUE.md#L16) and atlassian's [`cloudId`](https://github.com/m2ux/workflow-server/blob/bb38d574/corpus/support/atlassian/techniques/TECHNIQUE.md#L12) are required of every operation beneath them.
- **No check holds the class.**
  The entry is applied by hand, and its proving instance in the cargo library was found in review.

## Proposal

- **The catalogue names the class.**
  An entry states the harm as the server produces it — a required slot shown as ambient context with nothing producing it — lists the sources that may hold the input, and orders the fix that re-homes it.
- **Each family's contract gives its operations a source.**
  Each input gets a `#### default`, an optional marker where its readers handle absence, or a narrower home among the operations that read it, as the entry's Fix orders.
- **A guard applies the entry.**
  It reports a step binding an operation that never reads a required inherited input where no variable, earlier output or deviation holds it.
- **workflow-design is exempt.**
  It is deprecated and is not edited, so the guard's exemption surface names it with that reason.
- **The guard joins the standard sweep once the corpus is clean.**
  Until then it runs by its own command.
