## Overview

The shared libraries declare required inputs their own operations never read, and the workflows that bind those operations inherit the slots with nothing to fill them. This epic sources the three inputs that remain once each workflow has sourced its own, and declares the defaults the workflow-engine techniques state in prose, so the inherited-input and fallback checks report nothing against the corpus.

## Problem

- **Three library inputs account for every residual finding.** With each workflow's own inputs sourced, [the inherited-input-never-spent guard](https://github.com/m2ux/workflow-server/blob/a6f80b8a/guards/check-inherited-input-never-spent.ts) still reports 39 sites, every one of them inheriting one of three declarations:
  - [`session_index`](https://github.com/m2ux/workflow-server/blob/d540eb14/corpus/meta/techniques/workflow-engine/TECHNIQUE.md#L12) — 23 sites, across meta, plain-language, prism-audit, prism-evaluate, readme-links-conformance, remediate-vuln, work-package and workflow-authoring;
  - [`work_goal`](https://github.com/m2ux/workflow-server/blob/d540eb14/corpus/meta/techniques/orchestration-patterns/TECHNIQUE.md#L12) — 12 sites, across cicd-pipeline-security-audit and substrate-node-security-audit;
  - [`evaluation_report`](https://github.com/m2ux/workflow-server/blob/d540eb14/corpus/prism-evaluate/techniques/resolve-findings/TECHNIQUE.md#L12) — 4 sites in prism-evaluate.
- **No workflow owns a library it borrows.**
  A workflow sourcing its own inputs cannot reach a slot its library declares, so the residue survives every per-workflow fix and the guard stays red whichever workflow is measured.
- **Four workflow-engine inputs state a fallback nothing declares.**
  [The declared-fallbacks check](https://github.com/m2ux/workflow-server/blob/71459f89/guards/check-declared-fallbacks.ts) reports `workflow_id`, `target_workflow_id` and `agent_id` in [`start-session.md`](https://github.com/m2ux/workflow-server/blob/d540eb14/corpus/meta/techniques/workflow-engine/start-session.md#L16) and `agent_technique` in [`take-activity.md`](https://github.com/m2ux/workflow-server/blob/d540eb14/corpus/meta/techniques/workflow-engine/take-activity.md#L24), each naming the value it takes when absent while its declaration carries no default.

## Proposal

- **Each library input gets a source where its spenders share one.**
  A required input the library's own operations never read takes a `#### default` its spending operations accept, an optional marker where they handle its absence, or a home in the smallest container its spenders share.
- **The session index is the server's, not the author's.**
  `session_index` is ambient to every authenticated call, so its declaration states what the engine supplies rather than a slot a step fills.
- **A stated fallback is a declared default.**
  An input whose prose names the value it takes when absent carries that value as its declaration's default, and the sentence is cut to what the value holds.
