## Overview

This epic gives every value a corpus workflow reads a producer, and empties the ledger that keeps the activity-variables guard quiet while they have none. Fourteen workflows read a hundred and three values that no step produces, no gate sets and the server does not seed, so each run reads them unset and the agent carrying the activity improvises or stops.

## Problem

- **A hundred and three reads have no producer.**
  The name is declared without a default, no step produces it as an output, a write or a `set`, and the server seeds none. `remediate-vuln` holds forty-seven, `plain-language` and `workflow-design` three between them, and the other eleven workflows the rest.
- **The guard's silence is bought, not earned.**
  Every entry in [the ledger](https://github.com/m2ux/workflow-server/blob/70c25ee0ada3bf97b46137d571530d76794365f7/ledgers/unproduced-read-triage.json) carries the verdict `fix-later`, so `check-activity-variables` reports nothing against the corpus.
- **A shared activity carries its gap into every workflow that lists it.**
  `remediate-vuln` names sixteen of work-package's activity files as its own, so one unproduced read is reported against both.
- **New workflows arrive with the same defect.**
  Five workflows added since the class was first swept carry seventeen reads between them, and the ledger suppressed each as it landed.

## Proposal

- **A value the request states is bound at the first activity.**
  A technique in the opening activity reads it out of `user_request`, and a gate asks for it when the request is silent.
- **A value another step owns is declared where it is produced.**
  The step that computes it declares it as an output or a write, so the name has one home.
- **A value with a sound starting point declares a default.**
  `#### default` on the input settles it, and the description says what the value holds.
- **A fixture binding settles a conformance specimen.**
  A specimen that measures a known case declares the case on the workflow, so it walks with no caller.
- **A step with nothing to verify says so.**
  Where the value a verification reads is a list the run never had, the step reports that there was none to put rather than reporting a pass.
- **Each row deletes its own ledger entries.**
  The commit that gives a value a producer removes that value's entries, and the guard reports any entry left behind as stale.
