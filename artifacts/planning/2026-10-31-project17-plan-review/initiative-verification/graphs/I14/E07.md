## Overview

This epic makes a check's colour mean something on the branch it grades. A walk test reads a corpus file the corpus does not hold, one step of the definition-verification workflow decides whether the suite and the cost gate run at all, the cost gate is skipped when the suite fails, and the guard sweep never runs on the commit a merge produces. Each check concludes on its own subject and reports its own verdict.

## Problem

- **A test pins a corpus path the corpus does not hold.**
  `tests/e2e/walk-protocol.test.ts` reads `midnight-system-review` activity files, so the file errors rather than asserting. `pinned-corpus-paths` holds that class and reports clean.
- **One step decides whether the suite runs.**
  `verify.yml` runs the definitions-call-the-tools step ahead of the suite and the delivery-cost gate, and a failure there leaves both skipped. The step measures the corpus against the tools the engine registers, and each side moves independently of the change under review: an undeclared `start_session` argument held the suite and the gate skipped on every pull request from 2026-10-07 to 2026-10-09.
- **A failing suite skips the cost gate.**
  The delivery-cost gate runs behind the suite in the same job, so a suite failure leaves the gate with no verdict. Observed on `i14/e03/main`, `i08/main` and `i10/main`.
- **The guard sweep never runs on the branch it grades.**
  `verify-corpus.yml` declares `pull_request` and `workflow_dispatch` and no push trigger, so the corpus tip is swept on a proposed merge and never on the commit the merge produced. Its last non-pull-request run was a hand dispatch on 2026-09-18.

## Proposal

- **A red check is cleared at its cause.**
  The unresolved corpus path is corrected where it is stated, so the check concludes on what it was asked to grade.
- **A step reports and does not gate.**
  The definitions-call-the-tools step reports its own pass or fail, and the suite and the delivery-cost gate run whatever it concludes.
- **The cost gate carries its own verdict.**
  It reports pass or fail on its own, so a suite failure leaves a cost reading rather than a blank.
- **The sweep runs on the commit it grades.**
  The guard sweep is triggered by what reaches the branch the corpus lives on, so its latest run reads that branch's tip rather than a hand dispatch.
