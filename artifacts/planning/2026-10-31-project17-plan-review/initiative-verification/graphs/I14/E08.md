## Overview

This epic makes a guard's report a statement about its subject. A guard that cannot reach the corpus describes the absence as a defect of what remains, a guard that inspected nothing names the wrong reason, a guard reads a library internal as a caller's obligation, and the command an audit is told to measure a definition change with varies the wrong side. Each instrument answers the question it was asked.

## Problem

- **Twelve guards report a missing corpus as defects.**
  Against a joined tree with the submodule unpopulated, twelve guards report findings naming the definitions while six exit unmeasured. Five of the twelve instruct the reader to delete triage ledger entries that are correct.
- **An unmeasured reason names the wrong absence.**
  `review-mode-gating` skips a workflow without an `is_review_mode` variable, then reports no activity files found on a corpus holding twenty-seven of them. An auditor records that reason, so it becomes a statement about the corpus under review.
- **A guard demands a signature the library forbids.**
  `check-routines` derives `owner` and `repo` from REST path templates inside the GitHub library's leaves, and reports every routine binding one for an undeclared read. The library addresses a repository by `repo_path` or `target_repo` and bars GitHub access outside its namespace.
- **An audit is pointed at an engine comparison.**
  The command a canon audit is told to measure a definition change with varies the engine and pins the corpus, so a corpus base passed to it resolves in the wrong repository and the run refuses.

## Proposal

- **A guard that cannot reach its corpus exits unmeasured.**
  The twelve join the six: an instrument that inspected nothing reports that it could not measure, and the sweep's exit says so.
- **An unmeasured reason names the condition met.**
  The reason a guard records is the condition it actually met, so an auditor reading it reads a fact about the thing it inspected.
- **A guard reads the contract the caller holds.**
  A routine's declared reads are measured against the library's shared contract, not against the path templates inside its leaves.
- **An audit delta varies the corpus.**
  A canon audit measures a definition change with the engine pinned and the corpus moved.
