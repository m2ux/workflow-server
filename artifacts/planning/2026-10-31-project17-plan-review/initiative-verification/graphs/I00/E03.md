## Overview

This epic makes every name in a workflow definition resolve, and checks each one against the thing it names, with the repository's checks and the running server agreeing on what a name means.

## Problem

A step names the operation it runs. A set of instructions names another set it wants applied. A paragraph cites a section of a reference. An activity borrows an operation another workflow authored. Some of those names are checked. Most are not. The ones that are checked are checked by code that disagrees with the code that resolves them at run time, so a citation can pass the repository's checks and return nothing when a run follows it. A program cannot read a name that resolves two ways.

## Proposal

One slug computation for the guard and the runtime. A section reference may name a path of headings. Every inline reference resolves through the loader the server uses, and its arguments are checked against the callee's declared inputs. Classify the argument-omitting sites. Enumerate call sites whose target is a variable. Verify bindings against the running workflow.

## Acceptance Criteria

- [ ] **AC1.** One slug computation is used by both the guard and the runtime.
- [ ] **AC2.** A regression test pins guard and runtime slug parity.
- [ ] **AC3.** Neither documented slug-failure class occurs.
- [ ] **AC4.** A section reference may name a path of headings.
- [ ] **AC5.** Single-segment section references behave as they do today, and their delivered text is byte-identical.
- [ ] **AC6.** Every inline reference resolves through the loader the server uses.
- [ ] **AC7.** Inline-reference arguments are checked against the callee's declared inputs.
- [ ] **AC8.** The argument-omitting sites — 198 sites and 230 unbound arguments — are classified as satisfied-by-name-match or genuinely unbound.
- [ ] **AC9.** The three rule-addressed-as-operation sites are repaired.
- [ ] **AC10.** Call sites whose target is a variable are enumerated and reported as beyond static reach.
- [ ] **AC11.** Bindings are verified against the running workflow, bringing the 143 unverified sites into scope.

- [ ] **AC13.** Every admitted call site carries a disposition.
- [ ] **AC14.** No second slug computation exists anywhere in the repository.
- [ ] **AC15.** No second reference grammar exists anywhere in the repository.
