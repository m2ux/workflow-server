## Overview

This epic runs every instrument the initiative's acceptance criteria name against the integration tips, and records pass or fail in one validation ledger before those tips merge into the long-lived branches.

## Problem

- **Every initiative criterion names an instrument and none shares a ledger.**
  Each one ends by naming a check, a walk, or a confirmation, and no file records the instrument, the tip SHAs, and the result together.
- **The pull requests sit on two branches.**
  Of the four pull requests that name this initiative, two target `main` (#440, #1008) and two target `workflows` (#439, #1009). None targets `workspace`.

## Proposal

- **One validation task.**
  One pull request runs every instrument the initiative's criteria name against the integration tips and writes the results.
- **One ledger.**
  The programme rebase record gains `e12-validation-ledger.md`: one row per criterion, with the instrument, the tip SHAs, and pass or fail.
