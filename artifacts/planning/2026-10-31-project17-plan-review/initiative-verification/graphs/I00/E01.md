## Overview

This epic picks one way to write a yes/no test, fails a test that does not parse when the definition loads, migrates every remaining test onto that way, removes the other, and holds a comparison to a path the value carries.

## Problem

The tests that decide whether a step runs can be written two ways — a short string like `count > 3`, and a nested block spelling out the same comparison. Both are legal. Each is evaluated by different code, and the two convert non-numbers differently. Of thirteen tests written both ways, five return opposite answers. A disagreement returns an ordinary-looking false with nowhere to observe it. A program cannot read a test that means two things.

A comparison against a path the value does not carry fails open. `x.length != 0` is true where `x` is a string, because `.length` resolves to undefined on a string and `!=` against a literal then matches, so a gate written for rows takes the branch meant for a non-empty collection and the arm that should have run is dead.

## Proposal

Settle one form. Fail a test that does not parse, in every position a test may occupy. Migrate the remaining tests onto that form on the evidence of the recorded number-conversion list. Sweep the nested gates that are still written the other way. Give a declaration the set of values it admits. Stop a comparison against a path the value does not carry from evaluating true, and name that path in the run.

## Acceptance Criteria

- [ ] **AC1.** No definition file can express a test the settled form does not describe.
- [ ] **AC2.** A test that does not parse fails the load, in every position a test may occupy.
- [ ] **AC3.** A gate that pauses for a person is dismissible under either form.
- [ ] **AC4.** Dismissibility is carried by an explicit marker rather than by which field is present.
- [ ] **AC5.** A dismissal the evaluator does not confirm against session values is refused.
- [ ] **AC6.** The four values that parse under neither form today parse.
- [ ] **AC7.** Actions get a gate rather than widening what the unconstrained field accepts.
- [ ] **AC8.** Every test rewritten off the second dialect is answer-preserving on the number-conversion list, not on inspection.
- [ ] **AC9.** The remaining nested gates — 95 `condition` sites and 27 `continueWhile` trees — reach zero.
- [ ] **AC10.** A variable declaration can name the set of values it admits.
- [ ] **AC11.** A comparison against a value outside that set is reported.
- [ ] **AC12.** The workflow tier's test-free graph edges are asserted, reproducing 192 edges across 18 workflows.
- [ ] **AC13.** Every nested gate rewritten in the sweep is answer-preserving on the number-conversion list, not on inspection.
- [ ] **AC14.** The definitions this epic changes carry no outstanding confirmed finding, as the canon audit's coverage report shows.
- [ ] **AC15.** A gate comparing a path the value does not carry does not evaluate true, as a run of that gate over such a value shows.
- [ ] **AC16.** A run meeting such a gate names the path it could not resolve, as that run's output shows.
