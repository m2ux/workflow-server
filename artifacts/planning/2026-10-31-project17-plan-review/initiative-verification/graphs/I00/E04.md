## Overview

This epic makes a bare supplied value a literal always, a reference always braced, and both placeholder grammars the dotted form, with a guard that holds the rule.

## Problem

Of 412 technique input bindings, 349 are a bare string — 85 percent — and of those, 193 name a session value and 156 are literals, with both forms in a single binding block. The server guesses: a bare string is a rename when it names a resolvable bag entry, otherwise a literal. The answer changes if an earlier step writes a colliding name. Two placeholder grammars sit beside that guess. Seventeen dotted placeholders already report as resolved while naming no producer. A program that walks a definition cannot guess.

## Proposal

Measure the 193 sites and the 17 silent resolutions. Make a bare supplied value a literal, and a reference braced. Use the dotted placeholder form in every resolver and every guard. Hold the binding rule with a guard; a second token grammar fails the grammar conformance check.

## Acceptance Criteria

- [ ] **AC1.** Every technique input binding is either a braced reference or a bare literal.
- [ ] **AC2.** The loader never infers whether a bare string is a reference.
- [ ] **AC3.** The 193 sites that name a session value are braced, checked against the W01 list, not against inspection.
- [ ] **AC4.** One placeholder grammar, the dotted form, is used by every resolver and every guard.
- [ ] **AC5.** The 17 dotted placeholders that report as resolved while naming no producer either resolve to a producer or fail the load.
- [ ] **AC6.** A new bare-as-reference fails the change that introduces it.
