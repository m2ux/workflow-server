## Overview

This epic is the typed language.

## Problem

The rules a definition must obey are written outside the definitions: 33 checking scripts, 148 catalogue entries, and 34 principles. Type-checking lives where nothing keeps it honest. The runner specification carries no compatibility obligation toward a later language. The case for this epic rests on measurements I00 has not yet taken.

## Proposal

Author definitions in a language whose checker enforces what the current scripts enforce. Disposition every script, catalogue entry, and principle. Make what a step may do part of its type. Declare presets, alternatives, and modules. Let the corpus check itself. Disposition instruction sets that only wrap a tool call.

## Acceptance Criteria

- [ ] **AC1.** Definitions are authored in a language whose checker enforces what the current scripts enforce.
- [ ] **AC2.** That language compiles to the structure named in I00 E07.
- [ ] **AC3.** Every registered rule id carries a verdict — retired, kept, or declined with the reason.
- [ ] **AC4.** Every anti-pattern entry the canon keeps as judgement carries a verdict — retired, kept, or declined with the reason.
- [ ] **AC5.** Every principle the canon keeps carries a verdict — retired, kept, or declined with the reason.
- [ ] **AC6.** A step declares the kinds of effect it may have.
- [ ] **AC7.** An activity's permissions are the union of its steps'.
- [ ] **AC8.** A workflow declares a ceiling, and compiling checks containment.
- [ ] **AC9.** The disclosure guarantee is expressed as a ceiling and holds at least as strongly as the 280-line analysis it replaces.
- [ ] **AC10.** The boundary between what the type declares and what the host enforces is stated explicitly.
- [ ] **AC11.** A preset can be declared, listed alongside workflows, and named at session creation.
- [ ] **AC12.** The values a preset fixes are recorded and survive a continuation.
- [ ] **AC13.** A write to a locked preset value is dropped and reported.
- [ ] **AC14.** Reachability is checked per preset.
- [ ] **AC15.** The wrapper workflow carries only what a preset cannot — its starting activity and its remaining setup.
- [ ] **AC16.** The wrapper workflow's variable declarations are inherited rather than restated.
- [ ] **AC17.** An alternative set is declared, and selection is checked in both directions.
- [ ] **AC18.** The drift entry keys on the declared alternative construct.
- [ ] **AC19.** Every shared body lives in a module named for what it is.
- [ ] **AC20.** No generic body is owned by a domain workflow.
- [ ] **AC21.** Activity-file rules reference shared bodies on the same terms workflow rules do.
- [ ] **AC22.** No test on the code branch reads the corpus, and something enforces that rather than stating it.
- [ ] **AC23.** No recorded measurement carries a corpus commit identifier.
- [ ] **AC24.** A corpus change can be verified without the code branch having merged anything first.
- [ ] **AC25.** Every instruction set that only wraps a tool call is dispositioned — direct call, or a recorded reason its body stays.
- [ ] **AC26.** Each tier has a constraint model, or the type definition that is the grammar.
- [ ] **AC27.** The checker is generated from that artifact.
- [ ] **AC28.** The whole-corpus compile fails on a shared body owned by a domain workflow, as a checker rule reports.
- [ ] **AC29.** Every corpus pull request's CI run reports delivery cost from a step in `verify-corpus.yml`.
- [ ] **AC30.** A guard registered in `check:all` regenerates every tier's checker from its formal artifact and fails when the result differs from the committed checker.
- [ ] **AC31.** A guard registered in `check:all` reconciles the disposition record against the rule ids in `guards/guards.ts`, the canon's anti-pattern catalogue and its principles, and fails on any entry without a verdict.
