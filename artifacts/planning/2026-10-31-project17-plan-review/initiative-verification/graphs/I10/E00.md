## Overview

This epic makes each work-package review leave one terse report and puts the full prism pipeline to the user as a choice, so a run spends what its change needs.

## Problem

- **A report and a method record per review.**
  Code review, test-suite review and strategic review each wrote a findings report and a method record of what it walked.
- **Code quoted, sources listed.**
  Report templates quoted code inline and carried trailing source tables, and no rule named the form a link takes.
- **Agent records as prose.**
  The deferred-items and follow-ups registers and the comprehension log were markdown though only agents read them.
- **The full pipeline imposed.**
  A complex change took the full prism pipeline in every implementation run, and the child workflow received names it does not declare.

## Proposal

- **One report per review.**
  The method records go, each report carries one Method line, and the report guides name code in words with links in prose, per the shared writing register.
- **JSON agent records.**
  The two registers and the comprehension log are JSON with an `agent` audience.
- **A prism decision.**
  A decision activity before post-implementation review measures the change, assesses whether the full pipeline is worth its cost, and puts that recommendation to the user; a review run takes the full pipeline headless.
- **The prism child's own names.**
  Post-implementation review passes prism the mode, target and description the decision settled, under the names prism declares.
- **The canon backlog.**
  The defects the lean-review audits found already present in the workflow are fixed in this epic.
