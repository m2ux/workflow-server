## Overview

This epic converges assumptions only where they are settled and settles them through one routine, so the other activities record what they surface and pay for no convergence.

## Problem

- **Convergence everywhere.**
  Design philosophy, elicitation, research, implementation analysis, plan-prepare, assumptions review and implement each converged the same log, and elicitation ran an unbounded reconcile loop of its own.
- **Empty records.**
  Five activities recorded assumptions straight after collecting them, when no outcome had been asked for.
- **Two copies of the settling run.**
  Assumptions review and implement each ran converge, assemble, interview and record, with a trailing record repeating what the interview recorded.
- **Two copies of the publish pair.**
  Submit and complete each resolved the publish branch and committed the planning files.
- **Integration branches tested against the long-lived ones.**
  Engine CI checks out `workflows` and corpus CI checks out `main`, so a pull request into an integration branch is tested against the other long-lived branch rather than its own initiative's other half.

## Proposal

- **Collect everywhere, converge where settled.**
  Elicitation, research, implementation analysis and plan-prepare collect into the log; design philosophy, assumptions review and implement converge it.
- **One settling routine.**
  `settle-assumptions` converges, assembles the residual set and interviews it, binding every value it passes between its steps.
- **One publish routine.**
  `publish-planning-artifacts` resolves the publish branch and commits the changed planning files for submit and complete.
- **Paired integration CI.**
  A pull request whose base is an initiative's integration branch is tested against that initiative's counterpart integration branch, where it exists.
- **Server tests that follow the definition.**
  The delivery test finds its sibling technique from the served activity, and the walk simulation sets the open set under the settling routine's materialised name.
