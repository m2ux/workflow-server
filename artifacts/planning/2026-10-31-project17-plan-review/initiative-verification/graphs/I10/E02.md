## Overview

This epic makes every name a routine passes between its steps reach the variable its reference site binds, held by the routine splice, the activity contract and the routines guard.

## Problem

- **Substitution rewrites only what a step spells.**
  A technique step that leaves an input or output unbound reads or writes it under its bare id, so an internal never reaches it, and a renamed input or output reaches it only where every site binds the name to itself.
- **A live miss in meta's activity loop.**
  Each caller hands the loop the child session's index and planning folder, and twelve of its steps read the parent's.
- **Dropped outputs leak.**
  An optional output a site leaves unbound had its bindings removed, so a technique still wrote the value into the host under its bare output id.
- **Member arguments lose their member.**
  A braced argument such as `{roster_entry.repo_path}` reached the body as `roster_entry`.
- **An id both read and written had two bindings.**
  The output binding silently replaced the input binding, and a default on such an id was discarded.
- **Do-while flags read as host values.**
  The activity contract read a do-while's continuation test at loop entry, so activities declared reads of flags their own loop body writes.
- **Own-activity reads count only in a fan branch.**
  The activity-variables guard counts an activity's own later steps as readers of its writes only where the activity is a fan branch, so any other write read only inside its own activity passes on a prose mention or not at all.

## Proposal

- **Local unbound outputs.**
  An optional output a site leaves unbound is renamed as an internal is, so the body still writes it and no host variable receives it.
- **Whole-path arguments.**
  A braced argument names the whole path it spells, member included.
- **One variable for an id read and written.**
  Such an id takes a braced argument naming a whole variable at every site, an output binding names the same variable, and the declaration carries no default.
- **Do-while tests after the body.**
  The activity contract reads a do-while's continuation test after its last body step.
- **A guard for the splice's reach.**
  The routines guard reports a body step leaving a routine name to its bare id wherever a site, a default, a local output or an enclosing routine renames that name, and a body writing a name declared only as an input.
- **Own later steps are readers.**
  The activity-variables guard counts an activity's own later steps as readers of its writes, for every activity.
- **The corpus bound to match.**
  Every routine the guard reports binds the names it passes, and the activities drop the reads their own do-while settles.
