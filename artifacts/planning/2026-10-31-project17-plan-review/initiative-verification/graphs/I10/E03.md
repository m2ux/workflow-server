## Overview

This epic runs the work-package workflow's independent work side by side: the automated post-implementation reviews as one fan, and research beside implementation analysis as another.

## Problem

- **Reviews in series.**
  Post-implementation review runs code review, structural analysis and test-suite review one after another, though none reads another's output.
- **Discovery in series.**
  Research runs before implementation analysis, and plan-prepare reads both, though neither reads the other.
- **Fans hold no gates.**
  A fanned branch may declare no checkpoint, and branches share the working tree and planning folder, so a file two branches write races.

## Proposal

- **A review fan.**
  Code review, structural analysis and test-suite review become checkpoint-free activities fanned from post-implementation review, which keeps the manual diff review gates, classification and the fix cycle at the join.
- **A discovery fan.**
  Research and implementation analysis run as branches converging on plan-prepare, and research's gates move to the join.
- **One writer for assumptions.**
  Each branch reports the assumptions it surfaces as a value, and the join writes them into the log.
