## Overview

This epic adds the operation that pins a repository checkout to an arbitrary named revision, a commit, tag, or branch head, and the routine that makes a set of checkouts ready at stated revisions.

## Problem

- **No named revision.**
  The library materialises worktrees for branch work and derives host repositories, but nothing brings a checkout to a caller-named revision and verifies the resolved commit.
- **No roster.**
  Multi-checkout readiness has no construct, though any claim derived from a checkout is only meaningful against a stated revision.

## Proposal

- **Pin.**
  The pin operation fetches, resolves the named revision to a commit, checks out detached, verifies the resolved commit matches, and answers with the commit actually landed. A revision that does not resolve is refused.
- **Readiness.**
  A readiness routine iterates a roster of checkout-and-revision pairs, in the routine shape existing conformance specimens already prove for iteration over rosters, and answers the resolved commit of each.
- **Boundary.**
  The library does not manage submodule pointers beyond what pinning requires, and it performs no remote write.
