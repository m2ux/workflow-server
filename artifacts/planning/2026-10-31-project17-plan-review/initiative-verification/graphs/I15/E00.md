## Overview

This epic makes the ground safe for the runner: stop two faults that lose work, and stand up the three measurements later work is judged against.

## Problem

A resume into a folder that already holds a run overwrites that run and hands back the same identifier against an empty session. Nothing in the response says anything was lost. Measured on a real work package: a cursor and one completed activity before, an empty cursor and none after.

Setup facts are a forty-eight-line procedure an agent follows every run, and the prose has been wrong. One run bound a repository named in a link rather than derived from the checkout. Another threw a session away at a cost of 81,762 tokens. A planning folder was written under the dated fallback for three days.

Nothing records which path drove a session. Of thirteen gates written both ways, five return opposite answers, and a rewrite that flips one produces no signal. Characters are counted per step, but a delivery does not say what it cost.

## Proposal

Refuse a second dispatch into an occupied folder, and leave the file untouched. Derive the repository, session, and planning folder server-side from the working directory, in one call. Record which path drove a session. Enumerate the gates that flip when the two number conversions become one. Emit one cost line per delivery and two warn-only fan-out ratios. Stop sending the unread workflow schema at bootstrap.
