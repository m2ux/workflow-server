## Overview

This epic makes the corpus index span several roots. Each root is walked for the directories it claims, those claims are reduced together, and the reduction that already resolves a name, reports an ambiguity and detects a shadowed library runs over the union. A namespace's path is qualified by its root's label so the reference that carries a contested name reaches one directory, and a single root carries no qualifier. The index that comes out is the value every lookup already accepts, so resolution through it is resolution as it is.

## Problem

The walk takes one root, and the index it builds assumes everything in it came from there.

- **The walk is rooted once.**
  [`indexCorpus`](https://github.com/m2ux/workflow-server/blob/62ee9612c0649c0a99653cdf2ab2ff5469b43be6/src/loaders/corpus-index.ts#L293) resolves a product root, descends from it, and keys every claim it finds against that one base.
- **A path assumes a single base.**
  `NamespaceLocation.path` is the path from the corpus root, so the same relative path arising under two roots yields one map key for two directories.
- **A contested name relies on the path.**
  [`check-namespace-collision`](https://github.com/m2ux/workflow-server/blob/62ee9612c0649c0a99653cdf2ab2ff5469b43be6/guards/check-namespace-collision.ts) reports a name two directories claim and leaves the path spelling live, which is what makes the collision cost no coverage.
- **Shadowing is measured within one tree.**
  `detectShadows` compares a namespace against the library folders of the shorter namespaces beside it, and a shorter namespace in another root is outside what it compares.

## Proposal

- **A walk per root, one reduction.**
  Each root is walked for its claims. The claims are concatenated and reduced once, so names, ambiguities and shadows are measured over everything served.
- **A label qualifies a path.**
  A root carries a label, and each namespace's path is that label joined to its path within the root. One root carries no label and no qualifier.
- **A suffix still reaches.**
  A path is matched against the end of a namespace's path, so every spelling an uncontested namespace answers to today answers to it still.
- **Equivalence with a nested arrangement.**
  Two corpora served as two roots resolve a reference to the artifact they resolve it to when one is nested inside the other, which is what lets a deployment retire a join.

## Acceptance Criteria

- [ ] **AC1.** A walk of several roots yields every namespace each of those roots holds, as the corpus-index fixture suite shows.
- [ ] **AC2.** A namespace's path carries its root's label when several roots are walked and carries no qualifier when one is, as the corpus-index fixture suite shows.
- [ ] **AC3.** A namespace name claimed in more than one walked root resolves under no name and is reported as ambiguous, as the corpus-index fixture suite shows.
- [ ] **AC4.** A library path that a namespace in one walked root and a shorter namespace's library folder in another both answer to is reported as shadowed, as the corpus-index fixture suite shows.
- [ ] **AC5.** A reference resolves to the same artifact through an index of two roots as through an index of those two corpora arranged as one nested tree, as the corpus-index fixture suite shows.
