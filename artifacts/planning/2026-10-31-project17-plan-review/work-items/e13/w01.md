## Overview

A project declares the criteria its epics carry.

## Problem

The guide hardcodes one project's required corpus criterion without a project-owned declaration contract.

## Proposal

Define the project required-criteria declaration with branch trigger, criterion text, identifying phrase and delivering-row name. Choose and document one config path and schema before implementing the reader.

### File-change declaration

The delivery change is bounded by these paths (directory and `**` entries include their descendants):

- `skills/work-planner/artifacts/epic-issue-body.md`
- `skills/work-planner/test/test_format.py`
- `config/**`

Tests, command definitions, callers and structure declarations are part of this boundary. Record actual changed paths and the evaluated commit in delivery evidence. If implementation needs another path, update this declaration and recheck contention before concurrent work proceeds. Planning evidence lives in this task's record folder.
