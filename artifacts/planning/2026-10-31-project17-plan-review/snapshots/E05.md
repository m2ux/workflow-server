## Overview

The plan follows what has landed. A task id links the pull requests on it, open or merged; a criterion ticks when it holds; a row ticks when it is delivered and its criteria are ticked; and an issue closes when its rows and criteria are complete. An initiative's work reaches a long-lived branch only once that initiative is whole.

## Problem

- **The plan went stale on delivery.**
  Work merged and nothing updated the issues, so the tracker described a state that had already passed.
- **No link from a row to its delivery.**
  A reader of a Work Breakdown could not tell which pull request delivered a row, or whether one was open on it.
- **A row ticked on sentiment.**
  Nothing tied a row's completion to its criteria, so a row could read as done while the conditions it covered were unmet.
- **No settled column for done.**
  Completion was recorded in different columns in different tables, so no check could read it.
- **Partial work on the trunk.**
  An initiative's pull requests merged to a long-lived branch as they passed, so a branch carried part of an initiative whose criteria were still open.
- **A mode named for its mechanism.**
  The mode that keeps the plan in step was named for updating, which described the call rather than the outcome.

## Proposal

- **Sync.**
  One mode brings the plan in step with what has landed, and is named for that.
- **Links from the row.**
  A task id links each pull request on it, open or merged, and a further pull request is linked after the ones already there.
- **Ticks that follow conditions.**
  A criterion ticks when it holds. A row ticks when it is delivered and every criterion its Coverage names is ticked. An epic closes when its criteria are ticked and its tasks delivered.
- **The last column.**
  Done is the last column of every Work Breakdown, empty while the row is open and a tick when it is complete.
- **Integration branches.**
  Each long-lived branch an initiative changes has an integration branch cut from it, and every pull request of that initiative targets it. The initiative stays open until each integration pull request has merged.

- [x] **AC1.** One mode brings the plan in step with what has landed, named for that outcome.

- [x] **AC4.** Done is the last column of every Work Breakdown, empty while the row is open.
