# Source Review

## Declaration Ownership

Exact file, directory and suffix selection use the existing resolver. A SKILL.md layout is selected by its explicit file entry. Typed entry validation rejects malformed options before checking a partial model. The finding registry exposes the new checks to rules.json declarations.

## Lexical and Citation Ownership

BlockSpans comes from one scan_blocks state machine. Structure, links, prose checks, invocation validation and interface checks derive their contexts from that record. Literal fences cannot change state inside an invocation, and an outer fenced specimen holds HTML as specimen text. Bold argument links are required contract reach without becoming operation callers.

## Procedure and Contract Ownership

Step sequences are grouped under their actual parent, supporting main mode steps, callable child procedures and artifact operations. Preambles occupy one complete line in the intro boundary, following an optional purpose summary. Inputs and Outputs resolve third-level Fields contracts in their local or related artifact. Apply/Follow routing checks executable calls and leaves field citations alone.

## Scope and Validation

Only the shared checker and its seeded-skill tests change. All installed declarations, live Work Planner documents, other skills and shared guidelines retain their bytes. Validation.md records complete local suite results, exact inherited finding equality and the bounded disclosure result. Final merge waits for coordinator review of the published task head.
