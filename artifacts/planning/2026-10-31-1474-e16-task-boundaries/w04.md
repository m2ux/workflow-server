**Component:** skills/work-planner/scripts/revision-check.py

## Overview

Resolve the supplied branch, tag or commit to a commit, create a temporary detached checkout, execute the supplied instrument there and clean up the checkout after success or failure. Preserve the instrument exit result and report cleanup failure. Existing user worktrees are outside the helper's ownership.

## Problem

The owning epic requires a separately verifiable result for AC6; a combined closure-and-checkout change obscures its prerequisites and validation.

## Proposal

- **Inputs.**
  Prerequisites: None.
- **Delivery boundary.**
  Resolve the supplied branch, tag or commit to a commit, create a temporary detached checkout, execute the supplied instrument there and clean up the checkout after success or failure. Preserve the instrument exit result and report cleanup failure. Existing user worktrees are outside the helper's ownership.
- **Validation.**
  Use a local repository fixture with distinct revisions; assert the instrument sees the resolved commit, its success/failure is retained, and no helper-owned worktree remains.
