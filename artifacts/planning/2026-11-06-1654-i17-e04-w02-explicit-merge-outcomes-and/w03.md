## Overview

Epic integration consumes explicit merge outcomes.

## Problem

Generic refusal handling and unconditional merged-state confirmation can continue after a terminal refusal.

## Proposal

Select terminal handoff/denial, fresh-evidence bounded GitHub retry and merged-result readback from the shared result. Keep the rule at the merge owner and the continuation at this caller.
