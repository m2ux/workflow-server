# W12 — Workflow Canon Routes Stated as Steps

> Work item · Created 2026-10-12 · Task [#1341](https://github.com/m2ux/workflow-server/issues/1341)

## Overview

A passage runs the commands it names where its author has written them as steps. Workflow Canon's Dispatch Route states three commands as a sentence, so the section a reader follows to dispatch an audit calls nothing the shared skill-file check can see. This row states that route as numbered steps, and records the judgment made over every other Workflow Canon section that names a command outside a step, so the move that follows runs on a measured scope rather than an inferred one.

## Problem

- **One section directs the reader to run commands and records that nowhere.**
  [`audit-dispatch.md#dispatch-route`](https://github.com/m2ux/workflow-server/blob/7012a503/skills/workflow-canon/references/audit-dispatch.md#L19-L21) reads "Use Plan Audit Assignments, Bind Audit Agent, then Write Audit Packet", which is a procedure in every sense but its form.
- **Three specifications stand with no caller at all.**
  `Plan Audit Assignments`, `Bind Audit Agent` and `Write Audit Packet` sit in `change-surface.md`, and the only passage that runs them is that sentence. The check reports nothing about them, which is also what it reports about a specification no procedure runs.
- **No feature of the prose separates a route from a description.**
  Mood, count, order and condition each divide one pair of the measured cases and join another, so the sections that name commands outside steps can only be judged one at a time, and the judgment has to be written down to be checkable.

## Proposal

The Dispatch Route becomes numbered steps, and every other candidate section is judged and recorded.

- **The route becomes three steps.**
  Each of the three commands takes a step, in the order the sentence gave them, and the detail the sentence carried stays with the command it belongs to. The section's closing statements about scripts and inventory packets remain prose, because they direct nothing.
- **A section converts only where it directs the reader to run commands in order.**
  A passage stating what commands achieve, offering a choice between them, stating a dependency between them, or describing a command's effect stays as prose. The author's intent decides it, not a feature of the sentence.
- **A citation inside a command specification is never converted.**
  A specification states how one command runs, so a citation standing in it names a sibling operation. The check reads specification lines out before counting steps, and the prose matches that reading.
- **The survey is the evidence.**
  Every Workflow Canon section naming a command outside a step is listed with its verdict and reason, so a later reader can check the line that was drawn rather than re-derive it.
