## Overview

The shared skill-file check reports a section that opens in another mood than its parallel siblings, so a skill states one kind of selection one way. `skills/workflow-canon/references/coverage.md` states what coverage a kind of change requires in four parallel sections, two of which direct the reader while two say what holds. The check decides the rule the guidelines now state, and the coverage file meets it.

## Problem

- **One file states the same kind of thing in two moods.**
  [`## Main Coverage`](https://github.com/m2ux/workflow-server/blob/ba441c2b8/skills/workflow-canon/references/coverage.md#L80-L82) reads "Install Engine Dependencies, Run Engine Checks and Run Delivery Gate establish the baseline", while [`## Workflows Coverage`](https://github.com/m2ux/workflow-server/blob/ba441c2b8/skills/workflow-canon/references/coverage.md#L100-L102) opens "Use Run Guard Suite …" and [`## Docker Coverage`](https://github.com/m2ux/workflow-server/blob/ba441c2b8/skills/workflow-canon/references/coverage.md#L115-L117) "Check Shell Syntax for changed helpers". All four select the coverage a kind of change requires.
- **The imperative section carries words that read as an order of work.**
  Docker Coverage's *then* states that one command depends on another, and an imperative sentence carrying *then* is what a route looks like. A reader cannot tell a dependency from an instruction here.
- **No check reads the mood.**
  The step rule makes these sections' silence about calls correct, and nothing else reads the prose, so the mismatch stands until a reader trips on it.

## Proposal

A reader opening a coverage section to choose checks meets each section stating what its commands establish.

- **The guidelines state the rule.**
  Sibling sections whose titles end in one word state one kind of thing, so each opens in the same mood. A dependency between commands is stated as one, and a section directing an order of work is a procedure.
- **The shared check decides it.**
  Sibling headings with a common final word form a set. The first words of each one's opening sentence decide its mood: a run of links followed by a verb, or a subject word, states; an instruction verb, or a run of links followed by a preposition, directs; anything else is not compared. The first decided sibling sets the mood; each other sibling in a different one is reported.
- **The coverage sections take one voice.**
  Workflows and Docker Coverage state what their commands establish, and Docker Coverage states that Exercise Review Container observes the image Build Review Image produces.
