# The Exclusion Names a Procedure's Citation — October 2026

> Planning record · Created 2026-10-12

## Executive Summary

W05 stopped the shared skill-file check reporting a specification that the file holding it also cites, so a specification already standing with the procedure that runs it draws no finding. The exclusion reads any citation from the holding file, and a catalog holds no procedure. A cross-reference between two specifications in `commands.md` therefore excludes one from the report: eleven entries fall out that way, each cited by a sibling specification and by exactly one procedure elsewhere. Nine more in `canon-context.md` and `change-surface.md` fall out the same way: neither file carries a Procedure, so eight are named by a passage of reference prose and one by a sibling specification.

It matters because W08 moves what the report names. A specification the report drops stays in the catalog although one procedure runs it, which is the state AC3 forbids. The scope of the move is whatever this rule reports, so the rule settles first.
