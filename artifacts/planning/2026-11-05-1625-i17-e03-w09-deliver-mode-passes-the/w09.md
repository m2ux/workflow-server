## Overview

Deliver mode takes the lane its request names and passes it to the survey, so the units it confirms and dispatches are its lane's. Nothing about the lane is stored per session.

## Problem

- **The request has no lane.**
  [Deliver Mode](https://github.com/m2ux/workflow-server/blob/b2844c821ce800ed3d12735bdf339049594e5ec5/skills/work-planner/modes/deliver-mode.md#procedure) selects a board and surveys its units; nothing in the run says which lane it serves.

## Proposal

A user asks one session to "deliver next, lane 2" and another to "deliver next".

- **The request names the lane.**
  The lane a request names is passed to every Plan Available Work call of the run; a request naming none passes none.
- **Nothing is stored.**
  The lane lives only in the request, so each run states it again.
- **Confirm shows the lane.**
  The confirm step shows each unit line's lane with its tasks.
- **The rule stays in Delivery Plan.**
  The mode links the lane admission rule rather than restating it.
