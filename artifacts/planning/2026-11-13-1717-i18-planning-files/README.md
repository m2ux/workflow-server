# Planning Files — November 2026

> Planning record · Created 2026-11-13

## Executive Summary

This record plans I18, which gives planning's files their owners in Work Planner. Engineering Branch becomes the one home of where engineering-side content lands and how, Planning Record states only what holds for every record, and each file a record holds is defined by the artifact whose subject it is. One epic, Record Ownership, delivers it in five rows, with a layout check that gates each new record before it is published.

It matters because a record's rules sit in three files with other subjects, and its files are written by habit: one content appears under several names across records, and nothing checks that a record's README lists what the folder holds. Records opened before the change stay as written.
