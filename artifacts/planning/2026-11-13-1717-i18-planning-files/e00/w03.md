## Overview

This task gives each file a plan's record holds its owner: the artifact whose subject the file is states the file's path within the record and its template, and links Planning Record for the folder.

## Problem

Plan-side record files are written by habit.

- **Paths are unstated or stated by the caller.**
  Plan Mode asks for "an output path in the record's folder" for each body and work item, Goal Trace says only "record the trace table in the planning record", Dependency Graph says "record the printed longest chains" there, and Plan Mode records findings, decisions and the lane map there. Records hold `bodies/i17.md` beside `e05-body.md` and `epic.md`, and `e00/w01.md` beside `work-items/e09/w02.md`, as the [file-kind survey](../file-kinds.md) shows.
- **Decisions have no owner.**
  Rules' Decisions bullet records each decision in the planning record, and no artifact states the file.

## Proposal

The scene: Plan Mode drafts I18 and its epic, traces the goal, reviews, checks dependencies and records the user's answers.

- **Each owner states its record file.**
  A Record File field in each owner states the path, relative to the record folder, and the template, linking Planning Record's Planning Folder:
  - Initiative Issue Body: `bodies/i<nn>.md`, its Template.
  - Epic Issue Body: `bodies/e<nn>.md`, its Template.
  - Work Item: `e<nn>/w<nn>.md` in a plan record, `<task-id>.md` in a delivery record, its Template.
  - Goal Trace: `goal-trace.md`, the Trace Table and ranked Gaps.
  - Review Finding: `review.md`, Finding Content and Decision State per finding.
  - Dependency Graph: `dependencies.txt`, the printed report; `joins.md`, the split-unit record lines its `R=` input reads.
  - Plan Change: `decisions.md`, the user's decisions and the change list, one Entry per line; no record writes `changes.md` or `change-list.md`.
- **Callers take the path from the owner.**
  Plan Mode's steps pass the owner's Record File rather than "an output path in the record's folder"; the lane map is a decision entry. Conventions' Bodies bullet links the body owners. Rules' Decisions bullet links Plan Change's Record File.
