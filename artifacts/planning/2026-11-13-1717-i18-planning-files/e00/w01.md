## Overview

This task adds the Engineering Branch artifact: the one home of where engineering-side content lands and how it lands. Planning records, design documents and every other file a work item declares on the engineering branch publish through it.

## Problem

The engineering branch's rules sit in three files that each have another subject.

- **The branch rule lives in Rules.**
  `rules.md`'s Planning-records branch bullet states the direct push, the absent epic base, task and review pull requests, and the expected bypass notice. Rules is the skill's cross-cutting reading discipline, not a branch's owner.
- **The commands live in Planning Record.**
  Find Engineering Worktree and Commit Planning Record, with the Shared Worktree guidance, sit in `planning-record.md`, so a design document a work item declares on the branch is published by a planning-record command.
- **Delivery Branches restates the exception.**
  Epic Bases and Task Branches each carry the branch's exception inline beside a link to Rules.

## Proposal

The scene: a delivery session finishes a unit whose work item declares `engineering:artifacts/planning/<folder>/design.md`, and a planning session publishes its record. Both reach the same commit-and-push sequence.

- **Engineering Branch owns the branch.**
  `artifacts/engineering-branch.md` holds the branch rule as a Guidance section: direct pushes, no epic base, task pull request or review pull request, a unit changing only this branch opens no pull request and its rows link the pushed commit, and the remote's bypass notice is expected and goes unreported. It holds Find Engineering Worktree, the commit-rebase-push command, and the Shared Worktree guidance.
- **One publish operation.**
  Engineering Branch's operation publishes whatever the engineering worktree holds and confirms the caller's own files reached `origin/engineering`. Deliver Mode's step for declared engineering files applies it.
- **Callers link the home.**
  Rules loses its bullet. Delivery Branches, Delivery Plan, Epic Issue Body, Pull Request, Deliver Mode, Epic Integration and Conventions link Engineering Branch; `deliver.py` and `sync.py` name it in their docstrings and comments.
