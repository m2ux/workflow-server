# W03 — Operation-Contract Check in the Standard Sweep

## Overview

The contract check compares each value an activity declares with the technique that fills it, and it reports nothing against the corpus. It is not an entry the standard sweep walks, and the registry test records a reason for that, so a declaration that calls a structure a scalar again leaves the sweep green. This task puts the check in the sweep and takes the exemption out.

## Problem

- **The sweep never starts the check.**
  [`check:all`](https://github.com/m2ux/workflow-server/blob/cc150880/guards/check-all.ts#L97-L100) walks the registry and nothing else, and the program [says it is not an entry](https://github.com/m2ux/workflow-server/blob/cc150880/guards/check-operation-contract.ts#L27-L28).
- **The registry test excuses the absence.**
  The map of scripts that run outside the sweep [names this program](https://github.com/m2ux/workflow-server/blob/cc150880/tests/guard-registry.test.ts#L149-L153), so a file on disk with no entry still satisfies the test that every guard script is registered or excused.
- **A regression of the same class leaves the sweep green.**
  The corpus assertion sits in the guard's own test and skips when no checkout is present. Corpus CI runs the sweep, which does not start this program.

## Proposal

- **One registry entry, the same shape as the others.**
  Id `operation-contract`, script `guards/check-operation-contract.ts`, corpus scope, authored form, the JSON finding protocol, and `npm run check:operation-contract`. `gatesServing` stays false: a mismatch is a convention finding, not a corpus the server cannot load.
- **The exemption leaves the map.**
  `guards/check-operation-contract.ts` is not a key of `outsideTheSweep`. A registered script has no reason recorded for running outside the sweep.
- **The header states an enrolled guard.**
  The note that the program stands outside the registry, and the count it was held out for, leave the file. What remains is the subject it measures.
- **The sweep run is the instrument, and the map is the other.**
  A test runs `check:all` with no filter and reads a report line for `operation-contract`. A test reads `outsideTheSweep` and finds this script absent.

## Work Breakdown

| Part | Description |
| --- | --- |
| Registry | Add the `operation-contract` entry and `check:operation-contract`. |
| Exemption | Drop `guards/check-operation-contract.ts` from `outsideTheSweep`. |
| Header | State the program as a registry guard. |
| Test | A run of `npm run check:all` whose report names `operation-contract`; the assertion that `outsideTheSweep` has no key `guards/check-operation-contract.ts`; the guard's fixture cases and its live-corpus run; `npm run typecheck`; the whole `vitest run` suite. |
