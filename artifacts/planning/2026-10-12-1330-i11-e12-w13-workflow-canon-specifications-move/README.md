# Workflow Canon Specifications Move to Their Callers — October 2026

> Planning record · Created 2026-10-12

## Executive Summary

Six command specifications of the Workflow Canon skill stand in a reference file while one procedure elsewhere runs each. Three are reached from the audit mode's procedure and the revise mode's, and three from the dispatch route that W12 stated as numbered steps. A reader whose step runs `Write Audit Packet` opens a file stating the whole change surface — capture, identity, applicability, evaluation, completion, freshness — to reach the one operation their step calls. This task puts each of the six in the file whose procedure runs it.

It matters because the placement rule binds every skill in the repository, and Workflow Canon is the skill the rule was first proved against. The shared check names each specification with the single file that runs it, so the work list is measured rather than judged, and the epic's claim that an operation is read where its procedure runs holds across both skills or neither.
