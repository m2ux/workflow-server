## Overview

The user's corrections to Work Planner were held as session memories, and one of them contradicted the skill: an epic review merged without the user's review. This hot-fix states each of those rules in the file that owns it.

## Problem

Epic Integration merged an epic review pull request into a target that needs no approval. Agent review findings could be deferred, and each round repeated the full review. Plan mode always raised a proposal. Several planning and session rules were stated nowhere in the skill.

## Proposal

- **Epic handoff.** Epic Integration ends at Hand Off, and Merge Delivery Pull Request hands off an epic review before any mutation. Submit Epic Merge is removed.
- **Agent review.** Every finding is fixed with the smallest edit, a later round re-checks only the fixes, and a speculative case is named in scope. `agent_review.py` no longer accepts the deferred disposition, and the kind finding fault is removed.
- **Planning.** A proposal is raised only for a major project, and smaller work is drafted from the confirmed goal. New issues are placed at Backlog. The proposals board is found by its prefix. A split states its size, and no criterion exists only to refuse a retired option.
- **Session rules.** These cover corrections as Revise hot-fixes, one paragraph per batch decision, a short review Overview and the engineering bypass message.
