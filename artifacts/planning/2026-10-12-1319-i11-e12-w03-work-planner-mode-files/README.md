# Mode Files Take the Canonical Shape — October 2026

> Planning record · Created 2026-10-12

## Executive Summary

W01 wrote the canonical set of top-level sections into the shared skill guidelines and taught `skills/scripts/check_skill_files.py` to measure it. The check now reports eight sections standing outside that set — Brief in Work Planner's deliver mode, Placements in its hoist mode, four in Workflow Canon's review mode and two in its audit mode — and five links in `review-criteria.md` that resolve by file order rather than by the heading they name. This unit clears both, across the two skills at once.

It matters because the rule and its instrument already stand. A check that is red against the repository it binds teaches people to ignore it, and an exemption list inside the instrument would ship a suppression with the rule it suppresses. W03 and W04 share one pull request: they are the same change in two skills, and the reviewer reads the rule's effect once rather than twice.
