# W10 — A Prose Route Calls the Commands It Names

> Work item · Created 2026-10-12 · Epic row E12 W12

## Overview

The shared skill-file check counts a file among a command specification's callers where one of the file's procedures runs the command, and recognises a procedure by its carrying a numbered step outside a fence in a top-level section. Workflow Canon states several of its routes as sentences. This row settles whether such a sentence runs the commands it names, which fixes how much of Workflow Canon the next row's move has to carry.

Three corrections have been made to this rule, each written against the cases in hand and each undone by the work that followed it. The test stated here is drawn from what a procedure is, and is tested against the cases that would break a test drawn from the cases.

## Problem

- **The rule has been settled by cases three times and has not held.**
  Each correction read the citations in front of it, drew the line where they fell, and was overturned by the next set. A fourth line drawn the same way lasts until the next sentence an author writes.
- **A route in prose and a mention in prose have the same shape.**
  The citations Workflow Canon states outside numbered steps run from genuine routes to statements of what a command does, and the two ends are not separated by anything a file records.
- **The silence over Workflow Canon is read two ways.**
  The check reports two findings there where a reading that counted prose routes would report fourteen. Zero callers is also the state of a specification that no procedure runs, which stands where it is, so the count alone does not say which holds.

- **Case 1 and case 2 are the same shape.**
  Both name three command citations in the order those commands run. AC15's wording selects both; only mood and the conditional lead separate them, and a reader asked which is the route gives two answers.
- **Case 1 and case 3 open the same way.**
  Both are imperative sentences beginning *Use* and naming several commands. Order separates them, so an order test splits a pair that a mood test joins.
- **Case 2 and case 4 open the same way.**
  Both begin on a command citation followed by a third-person verb about what the command achieves. Count separates them, so a count test splits a pair that a mood test joins.
- **No two of the four are separated by one feature.**
  Mood, count, order and condition each split a different pair and join a different pair. Every test over prose is therefore a conjunction fitted to the sentences in hand, which is what the three corrections before this one were.

## Proposal

- **The test: a passage runs the commands it names where its author has written them as steps.**
  A step is an enumerated item of a top-level section — an ordered-list item outside a fence, whatever the heading names the section. Prose naming a command names it, whatever the sentence's mood, order or count.
- **The numbered step is the declaration, not a proxy for one.**
  Enumeration is the author stating that the reader performs these, in this order, and is the only place a file records that intent. The reading this row rejects is that the markup stands in for a procedure recognisable without it; the four cases show there is nothing underneath to recognise.
- **The test is applied identically by the author, the reader and the check.**
  An author knows whether they wrote a step, a reader sees the same marker, and the check reads the same line. A rule whose three audiences cannot disagree is the one that survives the next piece of work.
- **A route stated as prose is a defect in the route, with a one-edit remedy.**
  Where a section does direct the reader to run commands in order, it states them as numbered steps, and the call becomes visible to the reader and countable by the check in the same edit.
- **The twelve silent specifications are a measurement, not a loss.**
  They record that Workflow Canon states routes as prose. Restating those routes as steps is [E12 W12](https://github.com/m2ux/workflow-server/blob/engineering/artifacts/planning/2026-10-12-1341-i11-e12-w12-workflow-canon-routes-stated/w12.md)'s own AC1 and belongs with the corpus, beside the move W12 carries.
