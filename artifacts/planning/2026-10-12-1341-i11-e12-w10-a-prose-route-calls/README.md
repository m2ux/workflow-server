# A Prose Route Calls the Commands It Names — October 2026

> Planning record · Created 2026-10-12

## Executive Summary

The shared skill-file check counts a file among a command specification's callers where one of that file's procedures runs the command, and recognises a procedure by its carrying a numbered step. Workflow Canon states several of its procedures as sentences instead: `audit-dispatch.md` reads "Use Plan Audit Assignments, Bind Audit Agent, then Write Audit Packet", which is three commands in the order they run and not an ordered list. The check sees no procedure there, so the specifications those routes reach have no caller and stand where they are. Over Workflow Canon that is the difference between fourteen findings and two.

It matters because the next row moves whatever the check reports over that skill, and a reader reaching `Write Audit Packet` opens a file stating the whole audit surface to find the one operation their step runs. Whether that reader's route counts as running the command is the question this row settles, and the answer sets the scope of the move behind it.
