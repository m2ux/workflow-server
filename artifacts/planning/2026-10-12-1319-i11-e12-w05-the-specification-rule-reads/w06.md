## Overview

The section rule reads a mode file's top-level sections against the set the guidelines name, the order they name them in, and the two of them that are mandatory. A mode file carrying no Procedure or no Rules is reported, so the rule measures the whole of what the guidelines state rather than the part the headings present can answer.

## Problem

- **The section rule never checks presence.**
  [`skills/guidelines.md`](https://github.com/m2ux/workflow-server/blob/9ed47b0d/skills/guidelines.md#L50) makes Procedure and Rules mandatory and the other three optional. The [rule](https://github.com/m2ux/workflow-server/blob/9ed47b0d/skills/scripts/check_skill_files.py#L155-L167) reads the second-level headings the file carries, judges each for membership and its place in the order, and asks nothing of the headings absent, so a mode file carrying neither mandatory section passes.
- **A mandatory section is the one a reader counts on.**
  Procedure holds the steps and Rules what binds the mode whatever step it is on. A reader arriving at a mode file takes both as given, and the rule that promises the file's shape is silent about the half of it that cannot be read off a heading.

## Proposal

The rule already holds the section set and walks every second-level heading of a mode file. Presence is the same set read the other way, so the correction asks the headings it has already collected which of the mandatory two they name.

- **A missing mandatory section is reported.**
  A `<name>-mode.md` carrying no `## Procedure`, or no `## Rules`, draws a finding naming the section it lacks. A file missing both draws one for each.
- **The finding names the file.**
  An absence has no line of its own, so it is reported against the head of the file, where the reader starts.
- **The optional three stay optional.**
  Prerequisites, Reference and Commands are named in the set and in the order, and their absence is no finding.
- **The specimens carry each fault.**
  A mode file with its Rules and no Procedure, and one with its Procedure and no Rules, each shown against the rule, beside the conforming mode file the suite already holds.

## Work Breakdown

| Part | Description |
| --- | --- |

| Test | The check's suite seeds a mode file missing Procedure and a mode file missing Rules, and the whole suite and the check over work-planner and workflow-canon both run |
