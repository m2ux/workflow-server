# The Check Reads Its Own Rules Whole — October 2026

> Planning record · Created 2026-10-12

## Executive Summary

W01 gave the shared skill-file check two rules: a command specification cited from exactly one file other than the one holding it, and a mode file whose top-level sections fall outside the set the guidelines name or out of its order. A review of the epic base over W01, W03 and W04 found four faults in those rules. The caller count drops the file holding the specification, so one its own procedure cites alongside a single other file is reported. Inside a catalog every third-level heading counts as a specification. A caller under another of the given roots raises `ValueError` rather than drawing a finding. And the section rule measures membership and order alone, so a mode file carrying no Procedure and no Rules passes.

It matters because the rest of the epic is measured by this instrument. W02 moves specifications on the strength of what the one-caller rule reports, and a false positive there is a specification moved out of the file that should hold it. A rule that reports what is not there, and misses what is, cannot settle the criteria that cite it.
