# Instruction Reaching a Role That Cannot Act — October 2026

> Work item · Created 2026-10-07

## Executive Summary

A definition can tell a role to do something the role has no way of doing, and nothing catches it: the instruction reads correctly on the page, the run meets it, and the agent improvises past it. The same holds for a stated fallback that no declaration backs — the prose promises a path the contract never offers.

This work delivers both checks and registers them in the standard sweep. Each has to report the defect at a corpus commit that carries it and report nothing against the current corpus, so a check that passes because it looks at nothing is caught here rather than trusted.
