## Overview

Advance mode reports each Ready unit’s lane from the returned queue lines.

## Problem

- **The report names only the existing queue lines.**
  A user cannot see the Ready-unit lane before selecting work.

## Proposal

- **Carry the returned unit report.**
  The report step shows each Ready unit and its lane alongside the queue’s other lines.
- **Use the queue’s existing inputs.**
  Plan Board Queue receives issue and delivery snapshots; the Lane cells are in those issue bodies.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | The report step and every Plan Board Queue invocation |
| Plan | Ready-unit lane report wording |
| Implementation | Advance Mode’s report step and returned-report descriptions |
| Review | The mode uses the Board Queue report and links the lane rule to its owning field |
| Test | Inspect the mode and run its document tests for Ready-unit lane reporting |
