# I16 Work Planner Through Prosiform — November 2026

> Initiative plan · Created 2026-11-02

## Executive Summary

I16 makes Work Planner a skill used through prosiform: its entry point bootstraps by running `pf`, each mode compiles within prosiform's default output budget with no warning, a link stands only where its reader must have the content and names the section it needs, and sub-agent hand-offs and conditional reads use prosiform's dispatch and deferral operators. The shared skill guidelines state those rules, the shared skill-file check enforces them over the skills named to it, and the shared guide defines each check the workspace runs.

It matters because prosiform compiles every local link into the bundle an agent reads. Written for a reader who follows links, five of Work Planner's modes overflow the default budget at head, its prerequisites compile whole modes a step runs in one case, and its hand-offs are prose a compiler cannot see. The plan carries forward the evidence of Binding Citations and settles at compile time what that plan proposed to walk.
