## Overview

The shared skill guidelines state the rules a skill used through prosiform follows, and the shared skill-file check enforces them over the skills named to it. Work Planner's own links, hand-offs and bootstrap are brought to these rules by the epics that follow, so the rules and the check exist before any skill is held to them.

## Problem

- **The Links rules assume a reader who chooses.**
  The [shared Links rules](https://github.com/m2ux/workflow-server/blob/785a5ee8c/skills/guidelines.md#L105-L118) type a selection link and a prerequisite citation, both read by an agent following links. Under prosiform every local link is a dependency, compiled whole into the bundle.
- **No rule states the bootstrap, the operators or the budget.**
  The shared guidelines name neither `pf`, nor the `⇉`, `⫽` and `¬` operators, nor a bundle's output budget.
- **The check reads resolution only.**
  The [shared skill-file check](https://github.com/m2ux/workflow-server/blob/785a5ee8c/skills/scripts/check_skill_files.py#L1025-L1029) confirms that a link resolves; a whole-file link to a file with sections, a mode linking another mode whole, and a mode that overflows the budget all pass.
- **Every skill the check reads takes every finding.**
  The check runs over each skill folder passed to it, and [workflow-canon's Revise Mode](https://github.com/m2ux/workflow-server/blob/785a5ee8c/skills/workflow-canon/references/revise-mode.md#L72-L73) runs it over a skill this work never edits.

## Proposal

- **The guidelines state the prosiform rules.**
  - A skill used through prosiform bootstraps from its entry point by running `pf` and following it.
  - A link stands where the reader must have the target's content, and names its section wherever the target carries one.
  - Prose that names another mode or file without sending the reader to it is plain text.
  - A sub-agent hand-off is `⇉`, or `⫽` for a set run together; material a step reads only in some cases is `¬`.
  - Each mode compiles within prosiform's default output budget with no warning.
- **The check enforces them over the skills named to it.**
  It reports a whole-file link to a target with sections, a mode or protocol reaching a mode file without an operator, and a mode whose compilation crosses the budget or warns. A missing or mismatched `pf` is a finding, never a skip. A skill is held to these findings by a command-line option naming it, which Work Planner's Revise Mode and the shared Verified rule pass.
- **Rules land before any skill is held.**
  No skill is named to the prosiform findings by this epic, so no branch carries a finding against a skill's own files.

## Acceptance Criteria

- [ ] **AC1.** The shared skill guidelines state that a skill used through prosiform bootstraps from its entry point by running `pf` and following it, as a read of the guidelines shows.
- [ ] **AC2.** The shared skill guidelines state that a link names a section wherever its target carries a heading below its title, as a read of the guidelines' Links section shows.
- [ ] **AC3.** The shared skill guidelines state that a link stands only where the reader must have its target's content, and that prose naming another mode or file otherwise is plain text, as a read of the guidelines' Links section shows.
- [ ] **AC4.** The shared skill guidelines state that a sub-agent hand-off is a dispatch link and that material a step reads only in some cases is a deferral link, as a read of the guidelines' Links section shows.
- [ ] **AC5.** The shared skill guidelines state that each mode of a skill used through prosiform compiles within prosiform's default output budget with no warning, as a read of the guidelines shows.
- [ ] **AC6.** The shared skill-file check reports a link naming no heading where its target carries one below its title, and none where the target carries no such heading, as the check's own test suite shows against a specimen skill carrying each.
- [ ] **AC7.** The shared skill-file check reports a mode or protocol file that reaches a mode file through a link carrying no operator, as the check's own test suite shows against a specimen skill carrying that link and one carrying a dispatch.
- [ ] **AC8.** The shared skill-file check reports each mode whose compilation under prosiform exceeds the default output budget or warns, as the check's own test suite shows against a specimen skill carrying an oversized mode and a warning mode.
- [ ] **AC9.** The shared skill-file check reports an absent `pf`, or one whose profile differs from the profile the check names, as a finding rather than skipping the compile, as the check's own test suite shows.
- [ ] **AC10.** The shared skill-file check reports prosiform findings only in the skills named to them, as the check's own test suite shows against a named and an unnamed specimen skill carrying one fault.
