## Overview

Work Planner's links carry the meaning prosiform gives them. Each names the section its reader needs, prose that only names another mode is plain text, a sub-agent hand-off dispatches the procedure the sub-agent follows, and material a step reads only in some cases is deferred. A mode's bundle then holds its own procedure and the sections it reaches, never another mode's.

## Problem

- **Links name whole files.**
  245 of Work Planner's 1075 internal links at [785a5ee8c](https://github.com/m2ux/workflow-server/tree/785a5ee8c/skills/work-planner) name a whole file whose content carries sections, and prosiform compiles each whole file it reaches.
- **Modes link modes whole.**
  - [Plan Mode's Prerequisites](https://github.com/m2ux/workflow-server/blob/785a5ee8c/skills/work-planner/modes/plan-mode.md#L11-L27) link Propose Mode and Sync Mode;
  - [Deliver Mode's](https://github.com/m2ux/workflow-server/blob/785a5ee8c/skills/work-planner/modes/deliver-mode.md#L11-L30) link Advance Mode and Hoist Mode;
  - [Sync Mode's](https://github.com/m2ux/workflow-server/blob/785a5ee8c/skills/work-planner/modes/sync-mode.md#L22) link Understand Mode.
- **A hand-off is a sentence.**
  [Deliver Mode](https://github.com/m2ux/workflow-server/blob/785a5ee8c/skills/work-planner/modes/deliver-mode.md#L101-L105) passes Run Delivery Session to a sub-agent through prose, and [Sync Mode](https://github.com/m2ux/workflow-server/blob/785a5ee8c/skills/work-planner/modes/sync-mode.md#L175) runs Understand Mode inline. No Work Planner link carries an operator.
- **Conditional reads compile unconditionally.**
  [Plan Mode](https://github.com/m2ux/workflow-server/blob/785a5ee8c/skills/work-planner/modes/plan-mode.md#L37) runs Propose Mode only when neither a proposal nor an initiative is named, and [its ninth step](https://github.com/m2ux/workflow-server/blob/785a5ee8c/skills/work-planner/modes/plan-mode.md#L109) runs Sync Mode only once work has landed; both compile into every Plan bundle.

## Proposal

- **Each link names its section.**
  A whole-file link stays only where its target carries no heading below its title.
- **A mode named in passing is plain text.**
  Prose that attributes a behaviour to another mode names it without a link, so nothing compiles.
- **A step running another mode or a sub-agent dispatches it.**
  The step links the procedure with `⇉`, or `⫽` for a set run together, and prosiform publishes that procedure as a bundle of its own.
- **A conditional read is deferred.**
  A step that reads material only in some cases links it with `¬`, and the case stands in the step.
- **Prerequisites carry what the mode always reads.**
  A file a mode reaches only through a dispatch or a deferral leaves its Prerequisites.
