**Component:** workspace:skills/guidelines.md

## Overview

The shared guidelines define each check the workspace runs.

## Problem

The Files rule says where checks sit and nothing says what any of them decides, which skills it binds, how it is run or where its tests live.

## Proposal

- A Checks section with one entry per check: what it decides, which skills it binds, how it is run and where its tests live.
- The entries cover the shared skill-file check, its prosiform compile run, and each check script under `skills/`.
- The Files rule links the Checks section for what a check is.
