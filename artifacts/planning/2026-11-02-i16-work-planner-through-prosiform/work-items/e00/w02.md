**Component:** workspace:skills/guidelines.md

## Overview

The shared guidelines state the prosiform operators and the per-mode budget.

## Problem

Nothing in the shared guidelines names `⇉`, `⫽` or `¬`, or a bundle's output budget, so a hand-off or a conditional read has no stated form.

## Proposal

- A Links rule: a sub-agent hand-off, or a step running another mode, is a `⇉` link to the procedure followed, or `⫽` for a set run together.
- A Links rule: material a step reads only in some cases is a `¬` link, with the case stated in the step.
- A rule: each mode of a skill used through prosiform compiles within prosiform's default output budget with no warning.
