## Overview

A differential test evaluates every converted step gate against the structured condition it replaced, on the assignments of the variables that site reads. The two forms are the same test only where both are evaluated, and a rewrite that changed which assignments pass fails here.

## Problem

- **A fixed lattice misses the values a variable admits.**
  The [lattice comparison](https://github.com/m2ux/workflow-server/blob/fbb9943f1da5f669f0bd3eb4265637edcf3365ed/tests/converted-gates.test.ts#L35-L116) assigns every variable the same ten values, so `operation_type == "audit"` and `operation_type == "review"` agree at every point of it.
- **An open variable has no finite product.**
  [Eight sites](https://github.com/m2ux/workflow-server/blob/cffb70f7/artifacts/planning/2026-10-07-750-i04-e05-w01-survey-every-structured-condition/survey.md#L83) read a variable whose declaration closes no value set, so every assignment of that variable is not a list.

## Proposal

The comparison reads the converted `when` from the corpus this engine pairs with and the structured condition recorded for that step, and evaluates both on every assignment of the variables the site reads.

- **Closed declarations are enumerated.**
  Each variable contributes every value its declaration names, and absence when nothing seeds it. A boolean with no value set contributes true and false.
- **An open declaration is sampled, and the sample is not trimmed.**
  It contributes absence when unseeded, null, false, zero, the empty string, every literal the condition compares that variable to, and one further value of the declared type. The product of those values is evaluated whole.
- **Agreement is the two results.**
  The converted `when` matches the structured condition. Where the step already carried a `when`, it matches that expression conjoined with the condition. A single disagreeing assignment fails the comparison.
