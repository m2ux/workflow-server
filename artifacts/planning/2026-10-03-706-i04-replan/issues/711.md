## Overview

This epic runs the full coverage walk on a push to the default branch and on a schedule. A pull request whose diff cannot move option coverage does not walk.

## Problem

- **A no-move pull request already skips.**
  [coverage.yml](https://github.com/m2ux/workflow-server/blob/6355c392/.github/workflows/coverage.yml#L13-L15) runs on pull request and manual dispatch. The walk step is [skipped when the scope is none](https://github.com/m2ux/workflow-server/blob/6355c392/.github/workflows/coverage.yml#L128).
- **Nothing runs the full walk on push.**
  The workflow has no push trigger, so a merge to the default branch does not walk the roster.
- **Nothing runs the full walk on a schedule.**
  The workflow has no schedule, so a quiet week on the default branch does not walk the roster.

## Proposal

- **Leave the pull-request scope.**
  A pull request walks the workflows its diff can move, and skips when that set is empty. A borrowed engine whose walker, policies, or coverage helpers moved, or a change to the roster, walks the full roster.
- **Run the full walk on push.**
  A push to the default branch walks every workflow the roster names.
- **Run the full walk on a schedule.**
  A schedule walks that same roster.
