## Overview

This initiative pays down cost the definitions and the server still carry: walks that do not lock a record, classes a reader finds that no check looks for, a continue path that mints a replacement the boundary reading does not ask for, a coverage walk that does not run when a pull request is not the place for it, a step that can be gated two ways, declarations a check reads that are missing or wrong, and two guards whose quiet depends on a ledger and an acceptance list.

## Problem

- **The walks do not lock the records.**
  The artifact contract is the union of technique `#### artifact` declarations, [deduped by filename](https://github.com/m2ux/workflow-server/blob/ab680d9d/src/tools/workflow-tools.ts#L336-L339). The [review-mode snapshot](https://github.com/m2ux/workflow-server/blob/ab680d9d/tests/e2e/snapshot.test.ts#L139) asserts that create-mode checkpoints stay unpresented.
- **Three reader-found classes have no sweep.**
  No guard flags an instruction a role cannot act on, or a fallback stated only in a description. [AP-156](https://github.com/m2ux/workflow-server/blob/6355c392/corpus/canon/resources/anti-patterns.md#L2289) is in the canon, and the [rule-hygiene audit](https://github.com/m2ux/workflow-server/blob/6355c392/corpus/workflow-design/techniques/audit-rule-hygiene.md#L33) does not name it.
- **Continue-batch mints a replacement.**
  [finalize-activity](https://github.com/m2ux/workflow-server/blob/6355c392/corpus/meta/techniques/workflow-engine/finalize-activity.md#L28-L30) copies `may_continue` from `get_activity` onto the envelope. [continue-batch](https://github.com/m2ux/workflow-server/blob/6355c392/corpus/meta/techniques/workflow-engine/continue-batch.md#L60) mints a worker when that envelope is missing.
- **The full coverage walk has two missing triggers.**
  [coverage.yml](https://github.com/m2ux/workflow-server/blob/6355c392/.github/workflows/coverage.yml#L13-L15) runs on pull request and manual dispatch. A pull request whose scope step reports nothing [skips the walk](https://github.com/m2ux/workflow-server/blob/6355c392/.github/workflows/coverage.yml#L128).
- **A step can be gated two ways.**
  [`when`](https://github.com/m2ux/workflow-server/blob/ab680d9d/src/schema/activity.schema.ts#L59) gates a step. [`condition`](https://github.com/m2ux/workflow-server/blob/ab680d9d/src/schema/activity.schema.ts#L64) gates a step and, on a checkpoint, permits dismissal.
- **Declarations the checks read are missing or wrong.**
  Seven gitnexus operations declare [`#### entry`](https://github.com/m2ux/workflow-server/blob/6355c392/corpus/support/gitnexus/techniques/list-group-members.md). [`declared-type-mismatch` holds at 12](https://github.com/m2ux/workflow-server/blob/ab680d9d/guards/check-operation-contract.ts#L30), and that guard is outside the registry.
- **Two guards are quiet by list.**
  Unproduced reads are suppressed when the [triage ledger](https://github.com/m2ux/workflow-server/blob/6355c392/ledgers/unproduced-read-triage.json) says `fix-later`. Review-mode accepts three headless checkpoints in [the guard](https://github.com/m2ux/workflow-server/blob/ab680d9d/guards/check-review-mode-gating.ts#L51-L66).

## Proposal

- **Walks lock both records.**
  The all-workflows walk fails a delivered contract that announces one findings file twice. The review-mode snapshot walk fails a recorded assumption outcome.
- **A check for each class a reader found.**
  An instruction a role cannot act on, a fallback stated only in a description, and a rule that carries more than one constraint each have a check, and none of those checks reports a finding against the corpus.
- **Continue from the boundary reading.**
  The worker continues or respawns from the `next_activity` batch reading, and a continuation does not mint a replacement.
- **The full walk runs off the pull request.**
  A pull request whose diff cannot move option coverage does not walk. A push to the default branch runs the full walk, and so does a schedule.
- **One step gate.**
  A structured step condition becomes the equivalent `when` expression, or it is removed where its test cannot be false. Dismissal leaves the response tool.
- **Shapes where the checks read them.**
  A list entry declares the fields a step may read, and a contract declares each value with the shape the operation publishes. The operation-contract check runs in the standard sweep.
- **The two guards report nothing.**
  The activity-variables guard and the review-mode-gating guard report no findings against the corpus, as the standard sweep shows.

## Acceptance Criteria

- [ ] **AC1.** Every findings file an audit produces is announced once on the delivered artifact contract, as the all-workflows walk shows.
- [ ] **AC2.** A review-mode run records no assumption answer, as the review-mode walk of the snapshot suite shows.
- [ ] **AC3.** An instruction a receiving role cannot act on, a fallback stated only in a description, and a rule carrying more than one constraint under one heading each have a check or catalogue entry that fires on its historical instance, as each check's guard test and a rule-hygiene audit at the unsplit rule show.
- [ ] **AC4.** No check or catalogue entry for those classes reports a finding against the current corpus, as the standard sweep and a rule-hygiene audit of the corpus report.
- [ ] **AC5.** Continue-or-respawn follows the batch reading taken at the activity boundary, as a batched-dispatch walk shows when fetches after activity open exhaust the budget.
- [ ] **AC6.** A continuation mints no replacement worker, as a batch-loop walk of a missing envelope, a refusal, and a failed continue shows.
- [x] **AC7.** A second advance onto the activity already current is refused and records no completion, as the server-owned advance tests show.
- [x] **AC8.** A pull request whose diff cannot move option coverage runs no coverage walk, as the coverage workflow shows.
- [ ] **AC9.** A push to the default branch runs the full coverage walk, as the coverage workflow's triggers show.
- [ ] **AC10.** The full coverage walk runs on a schedule, as the coverage workflow's triggers show.
- [ ] **AC11.** No activity or routine step carries a structured condition, as the standard sweep shows.
- [ ] **AC12.** Every structured step gate holds as an inline gate, or is removed where a recorded measurement shows the test could not be false, as each converted gate's differential test shows.
- [ ] **AC13.** Each contract declares every value with the shape the operation filling it publishes, as the operation-contract check reports.
- [ ] **AC14.** The operation-contract check runs in the standard sweep, as the guard registry shows.
- [ ] **AC15.** The activity-variables guard reports no findings against the corpus, as the standard sweep reports.
- [ ] **AC16.** The review-mode-gating guard reports no findings against the corpus, as the standard sweep reports.
- [x] **AC17.** A second dispatch into an occupied folder is refused and the session file is left untouched, as the server-owned session setup tests show.
- [x] **AC18.** Every delivery records the path that drove the session and emits one cost-summary line, as the delivery cost record shows.

## Non-Goals

- Graph destinations that name several activities, which are a new capability.
- Deciding where fan-out is allowed.
- Changing the activity bound, its cap, its budget, or resume across a gate.
- Evaluating gates on the server, which stay agent-evaluated.
- Retiring the step kind discriminator.
- Removing version lines, or step ids the loader can derive.
