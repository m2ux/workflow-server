## Overview

The inherited-input-never-spent guard joins the standard sweep, so a new site fails the sweep at the change that introduces it.

## Problem

- **A guard outside the registry measures nothing by default.**
  The standard sweep and the edit guard run only the registered guards, so a step that leaves an inherited slot without a source passes both.

## Proposal

- **The scene.**
  The registry in `guards/guards.ts` lists every guard the standard sweep and the edit guard run.
- **Registration.**
  The guard gets a registry entry, and the guard-roster check names it.
