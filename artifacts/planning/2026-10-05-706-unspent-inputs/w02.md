## Overview

Workflow-authoring's container input `user_description` gets a source at every step that binds an operation which never reads it.

## Problem

- **22 steps owe a value nothing supplies.**
  [`user_description`](https://github.com/m2ux/workflow-server/blob/bb38d574/corpus/workflow-authoring/techniques/TECHNIQUE.md#L12) is required on the workflow's container. The operations bound in intake, scope-and-draft, quality-review and validate-and-commit never read it, and the workflow holds no variable or earlier output of that name.

## Proposal

- **The scene.**
  The request text reaches the workflow as the session's opening request, and a few operations read it.
- **The source.**
  Move the declaration down to the operations that read it, or give it a source the workflow already holds, as the entry's Fix orders.
