## Overview

A guard program that applies the inherited-input-never-spent entry, proven on the instance the entry was written for, so each family's fix is measured by the same test.

## Problem

- **The entry is applied by hand.**
  Its 125 sites were found with a one-off script that approximates the bag: it counts every output a workflow's techniques declare, in any order.
- **The proving instance has no test.**
  The cargo library's `build_scope` and `build_budget` fired where work-package binds `preflight` and `run-suite`, and nothing records that.

## Proposal

- **The scene.**
  A container `TECHNIQUE.md` declares inputs every descendant inherits. A step binds a descendant, and variable-binding fills each inherited slot from a deviation, the bag, or a default.
- **The check.**
  For each required container input, find the descendants whose own Protocol and Rules never reference it. For each step binding one, report the step where no workflow variable, no output an earlier step lands, and no deviation holds the input.
- **The exemption surface.**
  workflow-design is excused while it is deprecated, with that reason in the guard source.
- **The guard runs alone.**
  It is runnable by its own command and stays out of the registry until the corpus is clean.
