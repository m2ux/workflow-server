## Overview

The github, atlassian and git library contracts give every inherited input a source at each step binding an operation that never reads it.

## Problem

- **16 steps owe library contracts values nothing supplies.**
  - github's [`target_repo`](https://github.com/m2ux/workflow-server/blob/bb38d574/corpus/support/github/techniques/TECHNIQUE.md#L16) and [`repo_path`](https://github.com/m2ux/workflow-server/blob/bb38d574/corpus/support/github/techniques/TECHNIQUE.md#L12): 6 and 2 steps.
  - atlassian's [`cloudId`](https://github.com/m2ux/workflow-server/blob/bb38d574/corpus/support/atlassian/techniques/TECHNIQUE.md#L12): 6 steps.
  - git's [`planning_folder_path`](https://github.com/m2ux/workflow-server/blob/bb38d574/corpus/support/git/techniques/TECHNIQUE.md#L12): 2 steps.

## Proposal

- **The scene.**
  A library contract is bound from many workflows, each holding a different set of variables.
- **The source.**
  Mark each input optional where the ops reading it handle absence, give it a default, or move it to the ops that read it, as the entry's Fix orders. git's contract already describes `planning_folder_path` as one not every op needs.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | For each input, the ops that read it and the workflows binding those that do not |
| Implementation | Mark optional, default or re-home each input |
| Test | The guard over the three libraries, the standard sweep, and the library conformance specimens |
