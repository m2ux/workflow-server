# The Conventions Reached Without a Further File — October 2026

> Planning record · Created 2026-10-13

## Executive Summary

Epic I11 E12 took the execution conventions out of the command catalog and into `references/command-conventions.md`, so that a procedure reaching them would cost the conventions alone rather than the file holding every specification. The retrieval walk measured the result over every mode of both skills and found the opposite: nine of Work Planner's ten modes now open that file **and** still open the catalog, where one file served both before. No mode of either skill opens fewer files than it did, and Work Planner's total rose from 84 to 94.

It matters because the split was made on a retrieval argument and is the one decision this epic took that its own measurement contradicts. Either the conventions stand somewhere a mode already opens, or the claim behind the split is retired and the record says what the file buys instead. This record holds that decision and the evidence it rests on.
