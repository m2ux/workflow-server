# W14 — The Conventions Reached Without a Further File

## Overview

This task puts Work Planner's execution conventions in `SKILL.md`, the one file every mode opens to select itself, and retires `references/command-conventions.md`. A mode reaching the conventions then opens no file it would not otherwise open, which is the end state AC18 names. The shared guidelines state that placement as the rule for any skill, and Workflow Canon keeps its conventions where its two reaching modes already open them.

## Problem

- **The split was made on a retrieval argument the retrieval walk contradicts.**
  The epic's Proposal says the conventions move to a file of their own so that reaching them costs the conventions alone. The walk recorded nine of Work Planner's ten modes opening `command-conventions.md` **and** `commands.md`, where one file served both before.
- **No mode of either skill opens fewer files than it did.**
  Work Planner's files opened rose from 84 to 94 across ten modes, one per mode but Deliver, which rose two. Workflow Canon's total held at 27.
- **The gains the walk did find come from elsewhere.**
  Link-outs fell 31 percent and lines loaded 17 percent. Both are the catalog shrinking from 870 lines to 374 as specifications moved to their callers, which is W08's work, not the split's.
- **One mode paid the file and received nothing.**
  Plan mode opens one more file, localises no operation, and reaches the same eight operations through the catalog.

## Proposal

The conventions are one statement every specification assumes, and the file that every mode already holds is the skill's entry point. Putting them there costs no retrieval and keeps one copy.

### The options weighed

- **The conventions stand in `SKILL.md`.**
  Every mode opens the entry point to select itself, so the conventions arrive with the selection. One copy, and files opened fall by one for all ten modes.
- **The conventions return to the head of `commands.md`.**
  Restores the layout the walk measured as *before*. Nine modes lose the extra file, and Revise gains one: it is the single mode whose operations are now wholly in file, and it would open a 374-line catalog for the conventions alone.
- **The conventions are copied into each citing file.**
  Seventeen copies of one statement, each to be kept in step with the other sixteen. The mode-file section set the epic fixed — Prerequisites, Procedure, Reference, Rules, Commands — offers no heading a conventions block belongs under, so each copy would also distort the shape W03 gave those files.
- **The claim is retired and the file kept.**
  Legitimate where the file buys something retrieval does not measure. It buys a shorter read, which `SKILL.md` buys equally and without the file.

### The cost taken

- **One copy, carried by a file already open.**
  `SKILL.md` is the only file the walk charges to every mode unconditionally. Moving 24 lines into it leaves lines loaded within two lines of where they were and removes a file from every mode's retrieval.
- **Duplication is the cost refused.**
  Seventeen copies trade a retrieval cost of one file per mode for a maintenance cost of seventeen statements that must agree. One statement changed in sixteen places is a layout whose next author gets it wrong, and the epic's own rule — an operation several procedures share is stated once — argues against it on the same ground.
- **Revise mode decides against the catalog.**
  Folding the conventions back into `commands.md` is the only option that makes a mode worse than the layout before this epic. `SKILL.md` makes none worse.

### Workflow Canon needs no move

- **Its conventions file predates this epic.**
  `skills/workflow-canon/references/command-conventions.md` stands at `fae97e9e`, the walk's before commit, where pull request #1296 placed it.
- **Both modes that open it run an operation it holds.**
  Review mode and Revise mode are the only Workflow Canon modes whose files cite it, and each cites `Run Project Check` in it from a step of its own procedure. The file is opened for that operation whatever the conventions cost, so reaching the conventions opens no further file and AC18 holds for that skill as it stands.
- **Its remaining placement is another row's.**
  Where `Run Project Check` belongs is a placement question, and this row moves no command specification.

### The rule states the invariant

- **The shared guidelines name the test, not the file.**
  Skill-wide conventions stand where a procedure reaching them opens no further file: the entry point that selects the mode, or the file holding the operations those procedures already open. Both skills satisfy it, and a future skill is measured rather than told which filename to use.
- **The references listing drops the file it required.**
  `references/` holds a mode file per mode, the skill's own `guidelines.md`, and each guide the modes share.
