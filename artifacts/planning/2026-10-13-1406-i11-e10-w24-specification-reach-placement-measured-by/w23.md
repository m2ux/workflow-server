## Overview

Execution callers and required retrieval reach. The remaining work follows the current declared skill structure and preserves procedure-only caller semantics.

## Problem

- **The pending description mixes caller placement and retrieval cost.**
  A required citation may load content without executing the operation it names. Treating those as one relation changes placement for the wrong reason.
- **Historical placement claims omit the remaining delta.**
  The delivered rule and the current file structure must be checked before applying a move or claiming completion.

## Proposal

- **Caller counting observes execution.**
  A procedure running an operation contributes a caller. A sibling command specification or descriptive reference contributes none. Retain the existing caller fixtures and add only missing cases for the declared structure.
- **Retrieval follows required citations.**
  Include required command-specification links in the scenario's read set without changing execution caller counts. A merely descriptive link does not become a mandatory read; apply the current citation-loading rules.
- **Placement follows the declared architecture.**
  Work Planner uses modes, protocols and artifacts. Commands remain with their owning artifact when its structure keeps them there; shared behavior belongs in the appropriate protocol or artifact. No common catalog is introduced. Canon command normalization and conventions are owned by the separate Canon task.
- **Layout evidence compares equivalent scenarios.**
  AC34 supplies reproducible measurements for the final comparison owned by E14 W11. Use the pinned baseline and scenario contract in the retrieval decision, record the instrument revision and complete read traces, and report missing or incomparable cases. This task does not issue the final no-increase verdict.
