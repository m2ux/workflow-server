# Command Specifications in Steps — November 2026

> Hot-fix · Created 2026-11-18

## Executive Summary

The shared skill guidelines put each command specification in a `## Commands` section of the file whose procedure runs it, reached from the step by a `ƒ` link, so a step's command lives in a second place. The finding-classifier already places specifications in their steps, leaving the shared rules describing a layout one skill no longer uses.

The fix places each specification in the step that runs it across the shared guidelines, the shared skill-file check, and the work-planner, workflow-canon and gitnexus skills. A specification several steps run becomes an operation those steps apply.
