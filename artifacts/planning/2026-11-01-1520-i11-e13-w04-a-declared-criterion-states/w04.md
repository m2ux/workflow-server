**Component:** skills/work-planner/scripts/format.py

## Overview

A required-criteria entry names the paths whose change brings its criterion, and the format check holds an epic to that criterion only when its delivery pull requests change one of them on the declared branch. workflow-server's corpus-audit criterion states what leaves a finding outstanding, so a reader of the declaration can apply it without the retired guide text.

## Problem

- **Reaching the branch is the whole trigger.**
  An entry names only a branch, so any epic whose pull requests reach `workflows` is held to the canon audit. I11:E09 commits only `config/branches` to `workflows` and is reported lacking the audit.
- **"Outstanding" has no stated meaning.**
  The criterion requires no outstanding confirmed finding, and no file in the repository says when a finding is outstanding.

## Proposal

The format check reads `config/required-criteria.json` at the epic base and the epic's pull requests from the tracker. It knows which branch each pull request reaches, but not what it changes.

- **An entry names its paths.**
  Each entry carries `paths`, a non-empty list of files or directories on its branch. workflow-server's corpus audit names `corpus`, where the workflow definitions live on `workflows`. An entry without `paths` leaves the declaration unevaluable.
- **The check reads changed files from the tracker.**
  `format.py` takes `--files <number>=<path-list-file>` for each epic pull request, the list Fetch Pull Request Files saves. An epic is held to an entry's criterion when a pull request reaching the entry's branch changes a file at or under one of its paths.
- **Missing changed files are unevaluable.**
  A pull request reaching a declared branch whose changed files were not supplied, while none supplied touches a declared path, leaves that requirement unevaluable rather than met.
- **The criterion defines outstanding.**
  The corpus-audit criterion states that a finding is outstanding while it is neither fixed on the epic's branch nor taken by an issue.
