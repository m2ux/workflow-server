## Open Assumptions

### DP-7: How much of the epic this package delivers
**Assumption:** This package carries the inline-call work through to the canon and specification amendment, so the epic's acceptance criteria are this package's acceptance criteria.  
**Decision space:** *Full arc — W2 plus W3a plus the amendment.* The contradiction closes in one pass and the canon describes the running platform at every commit; the largest single change surface, and it cannot start before W0 lands. *W2 alone — the checker and the shared grammar module.* The smallest defensible increment: it hard-fails the unambiguous classes immediately, repairs the three malformed sites, and seeds the disposition worklist mechanically; it leaves 118 specification-sanctioned, canon-forbidden edges measured but undelivered. *W2 plus the amendment brought forward.* Closes the contradiction earliest, at the cost of future-dating the canon against a platform that does not yet deliver folds — the dual-home drift the canon exists to police, and the reason the doctrine record fixed amendment at delivery. *Migration batches in this package* is excluded rather than unconsidered: 118 edges are worked off a worklist across batches by the epic's own sequencing, and folding them in here would put an unreviewed pre-sort into the same change as the checker that produces it.  
**Why not code-resolvable:** it is a delivery-scope and release-sequencing choice about how much of an epic one pull request carries, not a fact recoverable from the codebase.  
**Technical context:** the epic sequences W0 before W3a, fixes canon amendment at delivery, and stages activation behind a server flag so the corpus never half-folds. W0's landing state is an unstated dependency in the full-arc option and needs pricing before that option is costed. The checker's hard-fail classes — unresolvable references, rule-addressed-as-operation syntax, malformed call forms — are exactly the sites canon and specification already agree are wrong, so they can land ahead of the amendment without taking a side in the contradiction.  
**Agent's position:** W2 plus the shared grammar module as this package's delivery, with W3a following once W0 has landed — the sequencing the epic already chose. The interim contradiction is tolerable precisely because the classes that fail hard are the ones both authorities condemn, and the contract classes stay delta-gated meanwhile.  
**Reversibility:** path-committing — the grammar module is imported by W3a's loader later, so its shape is committed by this package whichever scope is chosen.
