**Component:** workspace:skills/work-planner/scripts/sync.py

## Overview

A sync changes the Done cell of only the rows whose issue it was given. A row whose epic issue (initiative) or task issue (epic) is not given is unchecked: its Done cell stands, the run reports it `unchanged`, it shows no early tick, and the issue is not closable while it stays unchecked.

## Problem

`initiative_delivery` set `delivered[epic] = False` for a row whose epic was not among `--epics`, so `--fix` cleared its tick and the run printed only a `note:`. `epic_delivery` did the same for a row linking a task issue absent from `--tasks`.

## Proposal

- **Unchecked rows are left out of delivery.** Both delivery readers omit a row they hold no issue for; a row linking no issue at all stays undelivered.
- **Done, readiness and closure read only checked rows.** `sync_done` skips an absent row; ticked early names only known-undelivered rows; closable reports `unchecked <rows>` as its own reason.
- **The report names the row.** `unchanged: E00: its issue #2 is not given by --epics, so its Done cell stands`.
- **Prose states the rule.** The sync docstring, Initiative Delivery State, Sync Initiative, the epic Delivery Findings table and the sync-mode finish condition.
