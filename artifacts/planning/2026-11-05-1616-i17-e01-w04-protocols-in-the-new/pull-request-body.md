## Overview

All seven Work Planner protocols express their ordered actions as heading steps, require Rules and Conventions in one opening preamble, and route artifact and protocol calls through Apply and Follow. Live inputs, conditions, prerequisites and return paths are preserved. Strict protocol acceptance and complete suites pass on the actual W03/W04 composition. Disclosure observations remain Partial; the exercises do not establish complete workflows, strict reading order, full prerequisite closure or performance improvement.

## Changes

Protocol instructions expose their existing execution order and call boundaries in the approved style.

### Protocol Procedures

- **Ordered heading steps.**
  Thirty-two steps use numbered subsections, flush detail and scoped conditional groups. Every original prerequisite and checkout declaration is retained.

### Layered Calls

- **Explicit invocation links.**
  Artifact calls use Apply; whole-protocol calls use Follow. Retry links point to existing callees already required by their file, preserving the same inputs, guards and order.

### Evidence Boundaries

- **Partial reading observations.**
  Six repeated independent Deliver, Sync and Understand rehearsals retain actual receipts, recovered truncation, broad inherited prerequisites, incomplete closure/order and missing live evidence. The known retained-worktree gap stays with its existing dispatch-review work. Frozen protocol bytes match the implementation; actual merged reader support and base composition are tested separately.
