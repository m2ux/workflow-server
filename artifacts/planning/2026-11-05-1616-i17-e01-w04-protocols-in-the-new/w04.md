## Overview

The protocol family uses numbered heading steps and shared context preambles, exposing the approved presentation while preserving each protocol's complete execution path.

## Problem

The seven protocols encode their steps as list items. Artifact calls use several verbs, and common context is supplied only by callers rather than by each protocol's opening.

## Proposal

Each protocol already has its own prerequisites, checkout declaration and coordinated sequence. Add one opening line linking Procedure, Rules and Conventions; preserve Prerequisites exactly; express each numbered step as a title-case subsection with flush instructions and existing nested conditions. Artifact operation calls use Apply, and protocol calls use Follow. Keep every condition, supplied input, refusal, retry and return point. Coordinate necessary document readers with the mode-family worker. Installed model declarations remain the final adoption task's concern.
