**Component:** workspace:skills/work-planner/artifacts/hotfix.md

## Overview

The hot-fix entity's Board Status links Board Delivery's Status Changes for a closed hot-fix, so the closure rule has one statement.

## Problem

- **One rule, two statements.**
  Hot-fix Board Status says a hot-fix closed as completed is Done and one closed any other way leaves the board. Status Changes in artifacts/board-delivery.md states the same for every closed issue.
- **Drift.**
  The two agree now and part on the next change to either.

## Proposal

A planner reads a closed hot-fix's board status.

- **Board Status links the closure rule.**
  The Board Status line on a closed hot-fix links Status Changes and restates nothing of it.
- **No other restatement.**
  A skill file other than Board Delivery that states a closed issue's board status leaves it to Status Changes.
