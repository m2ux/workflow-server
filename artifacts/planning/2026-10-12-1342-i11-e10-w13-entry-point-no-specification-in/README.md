# Entry Point: No Specification in a Skill File — October 2026

> Task work item · Created 2026-10-12

## Executive Summary

The shared skill guidelines state that a skill's `SKILL.md` holds no command of its own: a command the entry point names is specified in the file whose procedure runs it, or in the catalog. The GitNexus CLI skill states five command specifications in its entry point, so every reader of that skill loads all five to reach any one of them.

Epic row E10 W13 carries this work, and its Coverage cell names AC19. This record holds the work item, so the friction, the design and the parts of the work stand where the epic row links them, and the issue that recorded the work is kept whole beside them.
