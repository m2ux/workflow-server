# Complete Source and Criterion Inventories

## Overview

Provide a read-only inventory command that captures the exact audit inputs and enumerates the complete source and canon surface for all four element types.

## Problem

- **Identifiers vary by construct.** Native IDs can be local to a loop or routine site; prose clauses may have none.
- **A source list can omit behavior.** Inherited contracts, materialized routines, consumers and supporting documents contribute audit obligations.

## Proposal

Capture revisions and file hashes, reuse inspected parser interfaces, and retain raw source addresses beside composed identities. Enumerate every AP and DP from its authoritative source. Include whole-section, whole-element, relationship and supporting-material rows, with explicit diagnostics for unresolved structure.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Confirm parser interfaces, source spans, schema fields and canon identity at the paired revisions. |
| Implementation | Add typed snapshot and inventory records, source adapters, dependency closure and the inventory CLI operation. |
| Review | Reconcile output against full sources and independently enumerated expected rows. |
| Test | Deliver T1 snapshot identity, T2 source inventory and T3 criterion inventory checks from the validation plan. |
