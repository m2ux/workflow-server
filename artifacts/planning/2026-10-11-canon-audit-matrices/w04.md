# Bounded Assignments and Durable Worker Results

## Overview

Calculate agent assignments from the actual work and context, then preserve exact coverage through dispatch, partial returns and restart.

## Problem

- **File counts misrepresent effort.** Applicable cells, full-source context and cross-element relationships determine the work.
- **Workers have finite capacity.** Failed or interrupted assignments leave residual obligations that must stay visible.

## Proposal

Measure a bounded pilot, partition by coherent criteria and source relationships, and calculate assignment counts from the accepted bundles. Respect host concurrency, preserve independent mapper/verifier roles, and reconcile durable attempts against each phase's exact required work set.

## Work Breakdown

| Part | Description |
| --- | --- |
| Implementation | Add calibrated cost inputs, semantic partitioning, exact ownership checks and dependency-aware dispatch plans. |
| Integration | Define host-agent requests and immutable worker returns with scoped read and edit authority. |
| Resume | Preserve accepted results and schedule the unresolved remainder after failures or capacity changes. |
| Test | Deliver T9 budget calibration, T10 assignment set reconciliation and T11 interrupted dispatch/resume checks, with representative agent execution. |
