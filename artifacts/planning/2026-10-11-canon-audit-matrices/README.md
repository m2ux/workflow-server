# Canon Audit Matrices — October 2026

> Skill change planning · Created 2026-10-11

## Executive Summary

This work plans a shared method for Workflow Canon authoring and retrospective audits. Before an audit pass, section tables in one Markdown document per element type map the change surface to applicable anti-pattern and design-principle criteria.

The intended outcome is a reviewable coverage map that is checked for accuracy before agents use it to evaluate and resolve violations. Large surfaces require a calculated distribution of audit work across agents, with explicit coverage of whole elements and affected relationships.
