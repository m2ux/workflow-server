# Independent Verification and Coverage Gates

## Overview

Make independently verified applicability a prerequisite for evaluation and complete current evidence a prerequisite for finishing an audit.

## Problem

- **A complete-looking map can exclude real obligations.** Missing source items and unjustified exclusions require independent checking.
- **Reports can outrun evidence.** A blocked criterion, partial worker return or stale result cannot establish complete coverage.

## Proposal

Accept mapping verification only from an independent role with source-backed receipts for the entire inventory and matrix. Validate evidence and ownership for evaluation results. Derive the audit-start and audit-completion gates from the reconciled state and preserve the distinction between coverage and conformance.

## Work Breakdown

| Part | Description |
| --- | --- |
| Implementation | Add verification receipts, discrepancy resolution, result ingestion and executable gate predicates. |
| Reporting | Generate coverage states and findings references from accepted current evidence. |
| Review | Exercise the complete capture–map–verify–evaluate–report lifecycle with bounded fixtures. |
| Test | Deliver T6 adversarial mapping review, T7 completion refusals and T8 result ingestion checks, including independent verifying agents. |
