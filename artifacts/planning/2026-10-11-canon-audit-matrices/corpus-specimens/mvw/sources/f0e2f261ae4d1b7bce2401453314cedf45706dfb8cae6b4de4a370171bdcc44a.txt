description: Refer to the API change gate over a route the graph holds under one verb with no consumer.

  reads:
    - positive_route_path
  writes:
    - name: positive_api_impact_report
      type: object
      description: The route's consumers, the response keys each reads, the middleware wrapping the handler, the execution flows it opens, and a risk level over the whole — one report, naming no consumer, for a route nothing in the tree fetches.
    - name: positive_api_change_approved
      type: boolean
      description: Whether the measured consumer surface was accepted at the gate. True where the measurement named no mismatch, the rating being low enough that no gate was presented.
      defaultValue: true

  - kind: routine
    id: gate-held-route
    routine: gitnexus::api-change-gate
    with:
      route_path: "{positive_route_path}"
    outputs:
      api_impact_report: positive_api_impact_report
      api_change_approved: positive_api_change_approved
exits:
  - id: gated
    isDefault: true
outcome:
  - The run measured what a held single-verb route's change reaches, landed one report rather than a set naming no consumer and no mismatch, and left the gate spliced from it unpresented with the approval at its seeded value
