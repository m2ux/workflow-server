title: GitNexus Tool Surface Conformance Workflow
description: >-
  Hold the gitnexus tool-surface run to two cases. The positive case names a tree registering MCP
  tools by calling a method, a shape outside the two the walk records as a tool node, so the run
  names the graph covering it and lands an empty inventory. The negative case names a markdown tree
  the graph holds with no tool declarations, so the run names that graph and lands an empty
  inventory too — the fallback it promises for a tree whose registrations the walk did not
  recognise, which the run's own note reads as such rather than as a tree defining none.
author: m2ux

  - routine

  activity:
    - variable-binding
variables:
  - name: repo_name
    type: string
    description: Name of the indexed graph every operation in the run addresses.
    defaultValue: workflow-server
  - name: positive_tree_path
    type: string
    description: Filesystem path of a tree registering MCP tools by calling a method, a shape outside the walk's tool detection, so the positive case's inventory is empty.
    defaultValue: /home/mike1/projects/dev/workflow-server
  - name: negative_tree_path
    type: string
    description: Filesystem path of a markdown tree the graph holds with no tool declarations, so the negative case's inventory is empty.
    defaultValue: /home/mike1/projects/dev/midnight-agent-eng/midnight-docs
initialActivity: positive-case
graph:
  positive-case:
    mapped: negative-case
  negative-case:
    mapped: report-cases
  report-cases:
    reported: __terminal__
