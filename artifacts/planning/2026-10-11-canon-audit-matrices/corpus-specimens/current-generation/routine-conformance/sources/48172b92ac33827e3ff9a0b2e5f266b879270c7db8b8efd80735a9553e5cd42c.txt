description: >-
  Hold the gitnexus api-surface-review run to two cases. The positive case names a tree whose graph
  serves API routes that nothing in the tree fetches, so the run names that graph, maps the routes
  it serves and lands an empty shape report, the check covering only routes with a consumer. The
  negative case prepares a throwaway checkout of source that serves no route, so the run builds its
  graph and both reads land empty — the fallback the run promises for a tree that serves no API,
  distinct from a tree whose routes were mapped and found consistent.
