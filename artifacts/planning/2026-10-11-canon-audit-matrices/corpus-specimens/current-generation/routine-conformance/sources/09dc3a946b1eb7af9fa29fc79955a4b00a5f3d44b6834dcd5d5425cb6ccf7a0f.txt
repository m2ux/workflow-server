# Project Techniques

Read and write a GitHub project: find the project, find an issue's item, read a field, write a single-select option.

The account that owns the project is the shared contract in [`TECHNIQUE.md`](TECHNIQUE.md).

| Technique | Contributes |
|---|---|
| [`find-project`](find-project.md) | Find a user-owned or organization-owned project by number or title |
| [`find-project-item`](find-project-item.md) | Find the project item that represents one issue |
| [`read-project-field`](read-project-field.md) | Read one project field, including single-select option ids, and the value on one item |
| [`write-project-field`](write-project-field.md) | Set a single-select project field to an option id and confirm it by re-read |
