id: plan-conformance
version: 1.1.0
name: Plan Conformance
description: Record when the run began, which roots the tree survey walks, and how many probes the instance fan opens.
variables:
  reads:
    - component_path
  writes:
    - name: run_started_at
      type: string
      description: When the run began, as an ISO 8601 instant. The baseline every branch's own interval is measured against.
    - name: probe_budget
      type: number
      description: How many directories the instance fan probes. The width the run opens, chosen before anything is surveyed so the survey cannot inflate it.
      defaultValue: 3
    - name: survey_plan
      type: object
      description: How the run surveys the component. Its `roots` hold the top-level directories the tree survey walks, one per instance, as plain slug strings — the first destination fans a member of its list over that path.
required: true
steps:
  - kind: technique
    id: open-the-run
    technique: plan-conformance
exits:
  - id: planned
    isDefault: true
outcome:
  - The run has a start instant every branch's own interval can be read against, so a reader can tell a batch from a queue
  - The instance fan's width is settled before any survey runs, so the width is a decision rather than a consequence
  - The first destination has the collection one of its members fans over, written by the activity whose own exit opens that fan
