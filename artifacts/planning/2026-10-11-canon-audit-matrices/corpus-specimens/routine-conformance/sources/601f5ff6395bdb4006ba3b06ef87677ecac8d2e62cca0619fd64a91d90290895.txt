title: GitNexus Graph For Tree Conformance Workflow
description: >-
  Hold the gitnexus graph-for-tree run to two cases. The positive case binds a tree a graph covers,
  so the first resolve names that graph and the build stays unreached. The negative case prepares a
  throwaway checkout carrying no graph and binds it, so the first resolve lands an empty name, the
  run builds a graph over the tree and names it — the fallback it promises for an uncovered tree,
  distinct from a tree whose graph is named at the first resolve.
