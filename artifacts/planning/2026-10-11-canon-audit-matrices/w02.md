# Section Matrices and Mapping Evidence

## Overview

Generate the four sectioned Markdown documents from a complete applicability ledger, with explicit evidence for every decision.

## Problem

- **Selected criteria conceal omissions.** Missing cells and implicit exclusions leave required checks undiscoverable.
- **Large tables need subdivision.** Formatting decisions can lose or duplicate parts of the logical matrix.

## Proposal

Create the complete row–criterion product and disposition each cell as applicable, reasoned not-applicable, or unresolved. Store mapping evidence in coordinator-owned state and render linked section tables in bounded row and column parts, preserving exact coverage.

## Work Breakdown

| Part | Description |
| --- | --- |
| Implementation | Add matrix state, typed mapping receipts, reason references and deterministic Markdown rendering. |
| Presentation | Produce the four type files, explicit empty-type records, criterion aliases and coverage views. |
| Review | Check section and table-part identity against the complete logical product. |
| Test | Deliver T4 matrix reconciliation and T5 mapping evidence checks from the validation plan. |
