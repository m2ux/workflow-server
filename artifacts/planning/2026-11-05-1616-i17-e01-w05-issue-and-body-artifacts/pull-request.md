## Overview

Issue and body artifacts expose linked input/output contracts and execute commands within numbered heading steps. The conversion preserves their conditions, command syntax, templates and prerequisite sections.

## Changes

### Artifact Operations

- **Execute commands in their steps.**
  The issue/body family uses raw HTML command blocks with contract-linked arguments and preserves existing callable anchors.

### Record Contracts

- **Name accepted inputs and returned states.**
  Complete JSON records, body text, identities, metadata and supplied versus posted comment states have distinct contracts.

### Template Reading

- **Recognize indented closing fences.**
  The template reader matches valid closing-fence indentation, character and length; malformed closers remain rejected.

### Interface Verification

- **Check heading procedures and script reach.**
  Document readers preserve linked contracts, step ordering, fetched-base inputs and cited executable coverage while excluding literal specimens.
