## Overview

Delivery, branch and pull-request operations carry executing commands and linked input and output contracts, so a caller reaches each operation's complete interface and ordered work together.

## Problem

The family separates command specifications from the operations that execute them. Input declarations and returned shapes remain prose, and numbered list steps have no callable heading boundary.

## Proposal

The six approved artifact files hold the delivery subject and its operations. Each operation keeps its callable anchor, declares linked contracts and executes commands inside numbered heading steps. Original Prerequisites, guards, argument order, quoting, examples and payload specimens remain authoritative. Distinct identities, complete JSON records, body text and draft metadata keep distinct contracts. Installed style declarations remain the final adoption task's responsibility.
