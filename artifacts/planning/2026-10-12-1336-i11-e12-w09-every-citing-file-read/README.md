# Every Citing File Read the Same Way — October 2026

> Planning record · Created 2026-10-12

## Executive Summary

The shared guidelines say a caller is a procedure that runs the command, and that a sibling specification or a passage of reference prose naming it does not make its file a caller. The check applies that reading to the file holding the specification and to no other. So a sibling specification's cross-reference counts when it stands in another file and not when it stands in the holding one, and a procedure stated under a heading of its own name — Delivery, Ordering Pass — is invisible where an h2 titled `Procedure` is required. Three specifications that now stand with the procedures running them are reported as misplaced, and one more has nowhere legal to go.

It matters because the check is the instrument every criterion of this epic names, and the move it was built to measure cannot pass while it misreads its own rule. This is the third correction the rule has taken, and each of the three was a case the reading had not been asked about. One symmetric, semantic test answers all of them at once.
