## Overview

Work Planner uses numbered heading procedures and named enriched command specifications. Commands precede Fields and own contextual input/output contracts; procedures select capabilities and preserve their guards and continuations. The skill's declared model drives shared validation while common runtime context has focused homes.

## Changes

### Shared Validation

- **Declared models.**
  Per-skill declarations select section layout, heading steps, preambles, command specifications, role tags and Run/Apply/Follow routing.
- **Literal boundaries.**
  One lexical reader distinguishes executable invocations from specimens and validates their linked arguments without treating payload text as procedure structure.

### Command Contracts

- **Contextual specifications.**
  Commands own an imperative action/result preamble, one linked HTML invocation and meaningful usage conditions; callers retain selections and result handling.
- **Readable arguments.**
  Encoded shell continuations preserve literal syntax; quoting follows value type, and Fields carry same-line inline examples while structural templates retain fences.

### Instruction Ownership

- **Focused context.**
  Rules, Conventions and Configuration have dedicated homes; in-text links select context, and Rules defines input, output and callable link roles once.
- **Data and procedures.**
  Fields describe values and valid-state constraints; single-use rules accompany their caller, shared policy has one Guidance home, and shared operations retain meaningful processing.
- **Preserved execution.**
  Explicit empty/optional values, output paths, formatter evidence, reservation dates, repeated base revisions and delivery/closure gates retain their consuming behavior.

### Consumer Validation

- **Actual contracts.**
  Fixtures execute documented invocations against real local readers and temporary repositories, covering concrete result shapes and failure evidence.
- **Current catalogue.**
  Test documentation and its reader describe current modules, root documents and counts, with the current target incorporated on the integration branch.
