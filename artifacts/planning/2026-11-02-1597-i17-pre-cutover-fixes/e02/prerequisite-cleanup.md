## Reading Contract

- Before-use prerequisites are ordering obligations, distinct from executing a called transformation and from consulting an ordinary linked field definition.
- Shared context is justified for every supported entry governed by it. Context required by only one branch, selected command or consumer is reached at that point of use with the smallest complete heading boundary.
- The audit records source, target section, entry condition, required content, reason, owning home, disposition and the scenarios that observe each edge.
- Remove redundant union-of-links preloads and correct misplaced shared guidance. Keep necessary rule content, authorization, checkout declarations, source identity, evidence gates, result routing and retry behavior.
- A visited-set shortcut does not prove an invalid ordering graph sound. Ordinary definition cross-references and intentional execution recursion are valid when they impose no circular before-use obligation.
- Rules, Conventions and complete common sections can be reused at the same source revision. Reading another mode as a document preserves its current execution distinction.

## Validation Design

### Structural Controls

- Reproduce the actual 13-artifact strongly connected component at the pinned source. Test self edges, a small multi-document cycle and a cross-file section cycle with exact source/target and a closed witness.
- Accept an acyclic diamond with shared context reused, an operation-specific prerequisite that is selected only when needed, ordinary cross-referenced definitions and a bounded execution retry.
- Exercise the production parser against fenced and HTML payloads so specimen links cannot create prerequisite edges or satisfy missing context.
- Trace supported direct and nested entries. Each required common section precedes its first use; no unrelated operation body is mandatory solely because its file contains a selected command or definition.
- Preserve all command payloads, field contracts and operative gates. Existing source suites and checkout/reader checks run in every fixing PR.

### Fresh Reading Trials

- Run Standup, Revise and Understand from clean pinned source, with actual captured input files and explicit authority limits. Use supported request windows; unsupported end-date behavior is a separate finding.
- Supply all task inputs, including current issue/PR evidence and an appropriate saved delivery checkpoint, so placeholders and absent source metadata do not manufacture a reading failure.
- Run at least two independent fresh-context trials per route and supported alternate entry. Record exact retrieved bytes/sections, order, reuse, truncation, missing required context, unrelated content and task correctness.
- Complete recovery of truncated required content is necessary; retain the original truncation in evidence. A structural pass does not substitute for observed reading behavior.
- Compare context volume only under paired equivalent tasks, inputs, source revisions and execution conditions. Make no savings claim from document or line counts alone.
