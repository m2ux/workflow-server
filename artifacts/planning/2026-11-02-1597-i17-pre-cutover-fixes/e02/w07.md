## Overview

Board Delivery obtains status decisions through Board Status and applies their results.

## Problem

Status Changes hides derivation and write-scope rules in a field, and Record Epic Review cites that field while performing a write.

## Proposal

Remove the mixed Status Changes field and route execution through the owning ƒ operations with supplied ○ evidence and ● results. Keep evidence gathering, application, retry/readback and convergence in Board Delivery.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Every operation and field reference to Status Changes and each associated script invocation and policy clause. |
| Plan | Map each policy clause to its audit-selected owner and each consumer to the new operation or result contract. |
| Implementation | Revise board-delivery.md operations, Fields and prerequisites for the extracted contracts; remove the old anchor completely. |
| Review | No forwarding field, duplicated policy, implicit IO or untagged operation remains; refusal and review-evidence gates retain their behavior. |
| Test | Run actual source/caller/checkout readers and status/board/delivery tests in the joined extraction; verify retry/readback and absent-item results as well as successful writes. |
