## Overview

A work item declares its component and describes its implementation. Lane assignment is the task row’s Lane cell in the epic table.

## Problem

- **The epic base holds a lane declaration.**
  The Work Item artifact at the W01 merge defines a Lane declaration and a population input, creating another location for a task’s assignment.

## Proposal

- **Component is the declaration.**
  Populate Work Item, Template and Sections describe Component and the implementation plan.
- **Lane has its table home.**
  The Work Item artifact links to the epic’s Lane field where context is needed; lane values are recorded in task rows.
- **Remove the declaration path.**
  Remove the Lane field, template line and population input, including operative descriptions and tests tied to that path.
