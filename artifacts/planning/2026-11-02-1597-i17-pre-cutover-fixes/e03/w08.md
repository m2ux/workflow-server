**Component:** workspace:skills/work-planner/scripts/deliver.py

## Overview

The available-work survey takes the lane a run serves and offers only the units that lane admits, so two Deliver sessions on one board never confirm the same unit. This is the filter prosiform's I10 waits on to run two sessions.

## Problem

- **The survey offers every unit.**
  `deliver.py` prints a `unit` line for every available unit, whoever the run serves, so a second session is offered the unit the first is about to hold.

## Proposal

Two sessions run the survey on one board, one with `--lane 1` and one with `--lane 2`.

- **A lane input.**
  `--lane <id>` names the lane the run serves. A unit is offered when every row’s Lane cell contains that index or every Lane cell is empty; a run without `--lane` is offered only unlaned units. Hot-fix units are unlaned.
- **The lane comes from the task table.**
  The epic body’s Lane cells are read through the shared dependency-module reader. A linked work item supplies the component; it does not supply the lane. Rows with no linked work item retain their table lane.
- **The unit line names its lane.**
  Each `unit` line carries the lane id, or names the unit unlaned.
- **Availability uses the existing evidence.**
  Holds, dependencies and delivery evidence decide availability; the lane filters which free units are offered.
