## Overview

Advance mode passes the engineering worktree to the board queue and reports each Ready unit's lane with the queue's other lines.

## Problem

- **Advance supplies no planning records.**
  [Advance Mode](https://github.com/m2ux/workflow-server/blob/b2844c821ce800ed3d12735bdf339049594e5ec5/skills/work-planner/modes/advance-mode.md#procedure) calls Plan Board Queue with board, pull request and issue evidence only, so the queue has no work item to read a lane from.

## Proposal

A user advances a board before starting one session per lane.

- **The queue gets the engineering worktree.**
  Each Plan Board Queue call passes it.
- **The report names lanes.**
  The report step reports each Ready unit's lane line with the other report lines.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Each Plan Board Queue call in the mode and the report step |
| Plan | The input's wording in each call |
| Implementation | Advance Mode's plan, resolve, write and report steps |
| Review | Every Plan Board Queue call carries the input |
| Test | The skill's mode and document tests over the changed mode |
