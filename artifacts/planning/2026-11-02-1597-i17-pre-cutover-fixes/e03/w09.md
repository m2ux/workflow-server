**Component:** workspace:skills/work-planner/scripts/board-queue.py

## Overview

The board-queue script prints each Ready unit's lane, read from the work items in the engineering worktree, through the dependency check's reader.

## Problem

- **The script reads no work item.**
  `board-queue.py` decides placements from board items, pull requests and issue bodies alone, so it has no lane to print.

## Proposal

The queue runs over a board whose Ready epic has rows in lanes 1 and 2 and unlaned rows.

- **An engineering input.**
  `--engineering` names the worktree holding the planning records; each Ready row's linked work item is read there for its lane.
- **A line per Ready unit.**
  Each unit whose rows Task Eligibility makes Ready is printed with its lane id, or as unlaned, under its epic's `next` line.
- **No placement depends on it.**
  The calls the queue writes are the same with or without lanes.
