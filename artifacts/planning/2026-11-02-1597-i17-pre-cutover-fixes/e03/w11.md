## Overview

The board queue reports each Ready unit’s lane from the epic task table so a user can see the lane beside the available work.

## Problem

- **The next line names epics.**
  The queue has the issue bodies containing their task rows, but its report names no Ready-unit lane.

## Proposal

- **Use the supplied epic rows.**
  Plan Board Queue reads the Lane cells already present in its issue snapshot.
- **Report each Ready unit.**
  A unit admitted by Task Eligibility is reported with its lane index, or as unlaned.
- **Placement uses priority and delivery state.**
  Lanes annotate the Ready-unit report. The existing placement inputs decide Status and assignees.
