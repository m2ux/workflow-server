**Component:** workspace:skills/work-planner/scripts/format.py

## Overview

The issue-format check validates the Lane cell and preserves it across table normalization, reservation and delivery recording.

## Problem

- **The format check has no lane condition.**
  Its table shape follows the epic template, but no lane value is checked and no fixture proves a Lane cell survives the row-writing paths.

## Proposal

- **Use the table’s declared shape.**
  The epic template supplies Lane after Joins and before Done.
- **Use the shared cell reader.**
  Validate Lane through the dependency module’s table-lane reader, reporting malformed populated cells with the task id.
- **Preserve values through row operations.**
  A valid Lane cell and an empty Lane cell retain their values when the table is normalized, rows are reserved or released, and delivery links or Done ticks are recorded.
