## Overview

Each task row carries its lane in the epic Work Breakdown table. The epic body owns the lane value used by planning, dependency checks, delivery and queue reporting.

## Problem

- **The table has no lane cell.**
  Its six columns hold task identity, description, coverage, dependencies, joins and completion; a lane cannot be recorded beside the task.

## Proposal

- **One Lane column.**
  The columns are `Task | Description | Coverage | Depends on | Joins | Lane | Done`.
- **A bare index.**
  A populated Lane cell contains only a decimal index such as `2`. An empty cell is unlaned. The index is opaque and board-wide.
- **The epic operation writes the value.**
  Populate Epic Issue Body accepts each supplied row lane and writes its Lane cell. Fields and Template own the shape.
- **One data source.**
  Work items hold the component and implementation plan. The task table holds lane assignment.
