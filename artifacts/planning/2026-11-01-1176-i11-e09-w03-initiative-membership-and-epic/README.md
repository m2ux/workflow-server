# Initiative Membership and Epic Activity Determine Status — November 2026

> Delivery record · Created 2026-11-01 · Revised 2026-11-01

## Executive Summary

This record holds the delivery of I11:E09 W03. A board's initiative status follows only the epics its table still lists, and an open epic stands In Progress while a task reservation or an open delivery pull request shows it active, until it passes the reviewed-handoff gate.

The board check reads these statuses, so an epic dropped from its initiative's table, or one with work under way that the board does not show, makes the board report a state its issues do not support. The work item carries the design and the test obligations for AC2 and AC3.
