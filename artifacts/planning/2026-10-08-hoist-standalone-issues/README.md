# Hoist Standalone Issues — October 2026

> Planning record · Created 2026-10-08

## Executive Summary

Seventeen open issues carried no agent-engineering prefix and no initiative linked them, so the work they describe sat outside every board and every dependency check. Ten of them are one family: a workflow reads a value nothing produces, and a `fix-later` entry in the triage ledger keeps the activity-variables guard quiet. The remaining seven divide into canon carve-outs and guards, test-plan evidence, audit conduct, the merge gate, and a hard checkpoint that an agent can answer.

This record holds the placement chosen for each issue and the Joins reasoning the new epics rely on. An empty Joins cell is only correct once a record names every eligible pair and says why it is not a pair, so that reasoning lives here rather than in the epic bodies.
