**Component:** workspace:skills/work-planner/guidelines.md

## Overview

The guidelines define SOLID ownership and bounded reading contracts for the skill's modes, protocols, artifacts and scripts.

## Problem

The ownership audit needs one published set of principles covering fields, transformations and prerequisite boundaries.

## Proposal

The reviewed SOLID draft supplies the model and principle definitions. Reconcile those definitions with the installed guidelines, linking each file-type section to the owning definitions and retaining all current layout, command and contextual-contract conditions. Register new labelled rules with the skill's rule map.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Compare the approved draft, current guidelines and rule map; identify existing equivalent rules and consumers. |
| Plan | Give each principle one home, with explicit field/operation and required-context boundaries. |
| Implementation | Publish the principle definitions and links from every governed file-type section, preserving current contracts. |
| Review | Read the complete guidelines for ownership, duplicate rules, valid links and exact applicability. |
| Test | Verify all five named principles, field boundaries and context constraints through the installed model, document checker and shared rule-map checks; run the required planner and shared suites and record consumer reading evidence. |
