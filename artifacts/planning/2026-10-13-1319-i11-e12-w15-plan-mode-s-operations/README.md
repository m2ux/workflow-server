# Plan Mode's Operations Placed or Recorded — October 2026

> Planning record · Created 2026-10-13

## Executive Summary

Epic I11 E12 moved a command specification out of the catalog wherever exactly one procedure ran it. Plan mode is the one Work Planner mode the rule never reached: the retrieval walk counts eight operations reached through the catalog and none in the mode's own file, and the mode's files opened rose from thirteen to fourteen, the widest retrieval in the skill. Every one of its eight operations is cited from more than one file, so the rule left each where it stood.

It matters because a citation is not a run. The symmetric caller test the epic settled reads a file as a caller only where one of its procedures runs the command, and the eight were counted against citations rather than against that test. This record reads each of the eight against its callers under the settled test, places the ones only Plan mode's procedure runs, and names the ones the catalog keeps against the procedures that share them, so the mode's retrieval is a measured floor rather than an open question.
