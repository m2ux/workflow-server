## Overview

This work authors the library resources for the new modes. A citation returns one section, and a procedure stays with the technique that owns it.

## Problem

- **The old guides mix consult material with procedures.**
  An existing guide may hold both what a worker looks up and steps a technique should carry. Design may use that guide, or re-interpret it into a new resource.
- **A section fetch returns the whole file.**
  The worker pays for every section when one would do.

## Proposal

- **A resource holds fill and consult.**
  - templates
  - vocabularies
  - criteria
  - policy

- **The library holds a new set.**
  Design may keep an existing guide when it already meets the need. The combined workflow keeps its own copies.
  - the plan guide
  - the findings guide
  - the close-out guide
  - the ADR guide
  - the elicitation guide
  - the design-framework guide
  - the assumptions guide
  - the review guides

- **The tests accompany the new resources.**
  A unit test fails when a library resource still contains a protocol cadence. An integration test fetches one section and fails when the response is the whole file.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Read the existing guides for consult material and for procedures a technique should own |
| Plan | Decide which artifacts to use as they are, and which to re-interpret into a new resource |
| Implementation | Author the library resources, at section grain |
| Test | A unit test for a protocol cadence, and a section fetch that returns that section |
