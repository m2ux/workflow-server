**Component:** workspace:skills/work-planner/SKILL.md

## Overview

The entry point lists each kind with the artifact that holds it and the interface operations it supplies, so general files reach kinds through one registration.

## Problem

SKILL.md lists the kinds but names no interface a general caller can select, so modes, protocols and artifacts link down to the hot-fix artifact directly.

## Proposal

A general caller that needs a kind-specific step currently links into `artifacts/hotfix.md`. The registration names each kind's artifact and the operations it supplies (hold release, dispatch status, delivery record, merge record, board settlement, body population, pre-merge review), each linking the general contract it fills. No second registry is created.
