# Graph Measurement Method

The detached review checkout is pinned to integration head dbfe21c2bc88d97034c3de8e64e8b490ae54688f. GitNexus 1.6.12 indexes that checkout in isolated temporary storage with index-only mode, without injecting files or generating embeddings. Current status and the repository resource confirm the indexed/current commit and content match; incomplete_reasons is empty. Comparison uses the exact freshly fetched workspace target d0a62b8037bb1b8fdafac5bf0e0035ada8c64486, not the main checkout's older local workspace branch.

The CLI detect-changes formatter prints at most fifteen symbol rows and ten affected flows even when its complete backend result holds more. The registered graph-measure.mjs calls that installed CLI's LocalBackend directly and preserves the complete result. It measures nineteen changed files, 156 changed symbols and forty affected processes. The heuristic critical risk label reflects shared graph reach; it is not a defect finding.

graph-details.mjs obtains a context for every changed symbol, all found, and queries every affected process by its reported name. Semantic name search can select another same-named process, so the script additionally reads exact STEP_IN_PROCESS edges by the actual reported process id. Every trace contains its full expected number of symbols and measured step_index values; no order is inferred manually. Both query payloads and exact-id traces are retained. Freshness is checked through repository context/status; this installed version omits the optional staleness field on current payloads.

The analyzer reports ranked-entry and branching budgets in graph-analysis.log. An absent ranked flow is not proof of an absent caller. The shared read_lanes function has measured callers but no ranked process membership, so four explicit CLI trace calls capture its actual one-hop CALLS paths from the dependency check, formatter, survey and Ready-unit reporter. The central sequence diagram uses those measured alternatives; the eligibility diagram uses exact proc_238_ready_units steps. Raw context records also expose receiver-typing lower-bound signals where the analyzer has them. The overview does not infer exhaustive dynamic call coverage from those signals.

The component edges come from measured call relationships, and the selected sequence steps come from actual graph traces. Source and behavioral fixtures independently establish lane validation, admission, table preservation and queue placement invariance. The full source/test diff and every current criterion are part of the agent review.
