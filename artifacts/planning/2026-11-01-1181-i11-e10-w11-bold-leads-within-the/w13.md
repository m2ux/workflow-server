**Component:** workspace:skills/gitnexus/gitnexus-cli/SKILL.md

## Overview

The GitNexus CLI skill's entry point states purpose and routing only. Its five command specifications sit in an operations file whose procedures run them, so a reader loads the one operation the request names.

## Problem

- **Five specifications stand in the entry point.**
  [`gitnexus/gitnexus-cli/SKILL.md`](https://github.com/m2ux/workflow-server/blob/ba441c2b/skills/gitnexus/gitnexus-cli/SKILL.md) carries `analyze`, `status`, `clean`, `wiki` and `list` under a Commands listing, which the [shared skill-file check](https://github.com/m2ux/workflow-server/blob/workspace/skills/scripts/check_skill_files.py) reports as `command specification in the entry point`.
- **No procedure runs them.**
  The [shared guidelines](https://github.com/m2ux/workflow-server/blob/workspace/skills/guidelines.md#commands) place a specification in the file whose procedure runs it. The skill states when to run each command in prose beside it, so no step anywhere runs one.

## Proposal

The CLI skill is one file: a heading per command, each with its command block, a flag table and a note on when to run it.

- **An operations file holds the procedures and the specifications they run.**
  `references/operations.md` carries a Procedure section with one sub-section for each request the skill answers: index a repository, generate a wiki, list indexed repositories. Each step links the specification it runs in the file's Commands section, which states each command as a one-line description, its flags as bullets, then its command block.
- **The entry point routes.**
  `SKILL.md` keeps its purpose, names what the skill acts on, links each procedure as the request that selects it, and names the tool and key the commands rely on.
- **Troubleshooting is conditional detail.**
  It moves to the operations file's Reference section, where a procedure reaches it.
- **The check settles it.**
  A run of the shared skill-file check over every skill reports no command specification in an entry point.
