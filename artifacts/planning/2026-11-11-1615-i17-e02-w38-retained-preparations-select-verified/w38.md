## Overview

Unit Dispatch selects creation for new work and verified reuse for a retained preparation, with its normal hold and start gates intact.

## Problem

The protocol takes retained preparation context and later unconditionally calls the operation that creates its task branch and worktree. A capacity wait can therefore resume into branch creation even though the recorded checkout already exists.

## Proposal

The existing automatic-dispatch correction supplies the worktree-validation capability and records the preparation head. Reconcile its new/retained branch selection with the separated protocol, using the owning Delivery Branches contract and completed prerequisite diagnostics. Keep selected context and result continuation at the call, including failure handling and the current start gate. Reuse the upstream helper and observing tests; correct defects at their owning implementation rather than duplicating validation here.
