**Component:** workspace:skills/work-planner/modes/plan-mode.md

## Overview

Plan mode asks whether an initiative uses lanes and proposes each row's lane for the user to confirm, so lanes are set where the rows are planned.

## Problem

- **No step assigns a lane.**
  [Populate the epics](https://github.com/m2ux/workflow-server/blob/b2844c821ce800ed3d12735bdf339049594e5ec5/skills/work-planner/modes/plan-mode.md#procedure) writes each work item with its component and nothing else, so lanes would be added by hand after planning.

## Proposal

A planner breaks an initiative into rows that two sessions will deliver.

- **One question per initiative.**
  Before populating epic task rows, the mode asks whether the initiative uses lanes, as an interview with a recommended answer.
- **A proposed lane per row.**
  When it does, the mode proposes each row's lane and the user confirms the map. Joined rows are proposed in one lane, as the dependency graph's Joins requires.
- **The task table records it.**
  Each confirmed row lane is passed to Populate Epic Issue Body, which writes the bare index in its Lane cell. Work-item population receives the component and implementation plan.
- **The finding comes from the check.**
  Joined rows in different lanes reach the planner through Check Dependencies and Numbering, which this mode already runs.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | The populate step's epic-body call and the interview conventions it follows |
| Plan | The lanes question's place and wording, and the proposal's basis |
| Implementation | Plan Mode's populate step: the lanes question, the proposed map and the row lane passed to Populate Epic Issue Body |
| Review | The mode links the task-table Lane and Joins rules rather than restating them |
| Test | Inspect the committed Populate the epics step for the initiative question, confirmed row map, joined-row rule and optional row indices supplied to Populate Epic Issue Body; run mode/document interface tests, the complete planner/shared suites and Check Skill Files |
