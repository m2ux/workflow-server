## Overview

Workflow-authoring's opening request is the value the session already seeds, and a step that binds an operation which never reads a required inherited input is not handed that slot with nothing holding it.

## Problem

- **23 steps owe the request under a name nothing seeds.**
  [`user_description`](https://github.com/m2ux/workflow-server/blob/c6774bff79af0e118b3de3532307c7ad40cd5d66/corpus/workflow-authoring/techniques/TECHNIQUE.md#L12) is required on the container. Intake classification and the update change brief read it; the other bound operations do not, and the session seeds the request as `user_request`.
- **27 steps inherit a required slot this run does not hold.**
  Borrowed operations inherit [`branch_name`](https://github.com/m2ux/workflow-server/blob/c6774bff79af0e118b3de3532307c7ad40cd5d66/corpus/work-package/techniques/TECHNIQUE.md#L28), [`problem_statement`](https://github.com/m2ux/workflow-server/blob/c6774bff79af0e118b3de3532307c7ad40cd5d66/corpus/work-package/techniques/TECHNIQUE.md#L20), [`requirements`](https://github.com/m2ux/workflow-server/blob/c6774bff79af0e118b3de3532307c7ad40cd5d66/corpus/work-package/techniques/TECHNIQUE.md#L16) and [`session_index`](https://github.com/m2ux/workflow-server/blob/c6774bff79af0e118b3de3532307c7ad40cd5d66/corpus/meta/techniques/workflow-engine/TECHNIQUE.md#L12), and workflow-authoring declares none of them.

## Proposal

The request text is the session's opening request. Two operations read it: intake classification, and the change brief assembled for an update.

- **The seeded name is the contract.**
  The container declares `user_request`, and the workflow variable of that name is the seeded request, so a step that does not read it still has the slot held.
- **A borrowing step names the slot.**
  Each step that binds an operation inheriting `branch_name`, `problem_statement`, `requirements` or `session_index` binds that input to the empty value. The operation does not read it, and this run holds none.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | The 23 steps that inherit `user_description`, the two operations that read the request, and the 27 steps that inherit a borrowed input this run does not hold |
| Implementation | Declare `user_request` on the container and the workflow, and point the two readers at it; bind each borrowed input to the empty value on the step that inherits it |
| Test | AC1: the inherited-input-never-spent guard over workflow-authoring reports no finding. The standard sweep, and the snapshot and coverage walks this corpus carries |
