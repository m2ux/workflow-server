# Technical Debt Split — October 2026

> Planning record · Created 2026-10-13

## Executive Summary

Technical debt is carried by three initiatives, one for each area the debt lives in: the server the engine runs, the corpus of definitions, and the instruments that grade both. Each holds the epics whose fixes land in its area, and each carries its own priority, so the order the debt is paid is a property of the area rather than of a reading order inside one large initiative.

The split makes priority expressible. A single initiative holds one priority label and one board position, so server debt and roster debt compete for the same slot and the board cannot say which is next. Three initiatives on the Mechanical board rank against each other and against the rest of the board, and an orphan issue arriving later has an area to join rather than a backlog to sit in.
