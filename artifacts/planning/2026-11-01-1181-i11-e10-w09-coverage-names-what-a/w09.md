**Component:** workspace:skills/work-planner/scripts/format.py

## Overview

The Work Breakdown Guide says a complete task's Coverage cell is empty, and the format check lets any ticked row carry an empty cell. A row's Coverage states which of the epic's criteria that row delivers, which is a fact about the plan rather than a status, so a complete row names the same criteria an open one does. This task retires the sentence and gives the rule a check.

## Problem

- **The guide states a rule nothing holds.**
  The [Work Breakdown Guide](https://github.com/m2ux/workflow-server/blob/workspace/skills/work-planner/artifacts/epic-issue-body.md) says of an epic's Coverage column that a complete task's cell is empty. `skills/work-planner/scripts/sync.py` ticks Done and leaves the cell naming what the row delivered.
- **The check takes a tick for an answer.**
  `skills/work-planner/scripts/format.py` skips the Coverage test for any row whose Done cell is ticked and whose Coverage is empty, so a complete row that dropped its criteria passes.
- **The sentence reads as a garbled neighbour.**
  Task grain says a delivered task's Coverage omits each criterion a further task adopts, so a row whose criteria a follow-up task delivers carries an empty cell. That is a rule about where a criterion is delivered, not about a row being finished.

## Proposal

A sync of an epic after its first task merges ticks the criteria that task covered, ticks the row and leaves its Coverage naming them. The table then reads as a record of which row delivered which criterion, before and after the epic closes.

- **Coverage names what the row delivers, whatever its Done cell says.**
  The guide drops the completion sentence, so one statement of the column stands.
- **The criteria a further task adopts still leave the cell.**
  Task grain is untouched. A delivered row whose criteria all moved to a further task delivers none, and the further task depends on it, so an empty cell stands on a ticked row that another row of the epic depends on, directly or through a range.
- **The format check holds the rule.**
  It reports an empty Coverage cell on an open row, and on a ticked row no other row depends on, and it reports a cell citing a criterion the epic does not state, complete or open.
