## Executive Summary

This record holds the revision that closes two ways a wrong shape reached the tracker unnoticed. A row of an epic could link an issue that was never converted into that epic's task issue, and a pull request body had a template and no check, so each session reproduced it from memory.

It matters because both gaps are silent. The unconverted issue is self-consistent as a standalone issue, so the issue-body checker passes it, and only the row that links it says otherwise; a pull request body answered to nothing at all. Both now have a mechanical reading, and the procedures that publish them run it.
