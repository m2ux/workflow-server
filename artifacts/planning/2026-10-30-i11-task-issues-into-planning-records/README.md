# Epic Rows Moved Off the Tracker — October 2026

> Migration record · Created 2026-10-30

## Executive Summary

Every task of the open I11 epics stood as its own tracker issue, and the board read one item per issue on top of the epic that carries its row. The planning detail each issue held now stands in a planning record the epic row links, so the board shows an initiative, its epics and their work, and the epic table remains the one statement of what a row delivers.

This record lists each issue, the record that carries it and the board status it held when it was retired, so a reader meeting an epic row that links a folder finds the issue it came from and the status the work last stood at. Each record keeps its issue's body and every comment unchanged.
