# Observed Disclosure Trials

Two fresh-context independent agents exercised completed-epic handoff and Sync of a previously In Review epic with changed target SHA, using read-only tools against the task worktree.

## Initial Trial

The first agent read SKILL, Sync and Deliver, integration/review protocols, board delivery, review evidence, change overview, acceptance/epic/delivery evidence and pull-request/branch/planning/body artifacts. It independently observed Sync's under-specified premature status call and preparation-before-withdrawal gap. A 13,776-token combined read truncated; the agent recovered the affected Pull Request and Delivery Branches ranges. Its transitive prerequisite reads were incomplete, so this is finding evidence, not a complete simulation.

## Repeat Trial

The second agent began in a fresh context with the same two realistic tasks and no expected routes or prior findings. It read complete SKILL and Sync, its 16 prerequisite documents, then Agent Review, Change Overview, Delivery Branches, Board Queue, Initiative, Requirement Characteristics, Planning Record, Pull Request Body, Repository Graph, Architecture Overview, shared guidelines and the validator. One oversized batch truncated; Board Delivery, Understand and Plan Change were retrieved again completely.

It confirmed entry withdrawal for both scenarios, current target invalidating earlier review, substantive review and published evidence before restored handoff, and separate human approval. It found a further command defect: Read Pull Request State selected append-to-JSON-lines while the validator needs one JSON object. After correction it re-read the operation and command and confirmed full REST metadata overwrites the snapshot on each refresh. No remaining handoff-route defect was identified.

## Limits

These are observed instruction reads and source-level routing checks. They did not execute GitHub writes or claim external handoff success; final live publication/readback is in delivery.md. Mandatory whole-document prerequisites still load unrelated planning/creation material. That existing disclosure boundary belongs to I11 E14; this task makes no context-saving claim and does not claim broad disclosure efficiency. Corrected prerequisite/call routes and structural conformance pass; excess disclosure and recovered truncations remain explicit observations.
