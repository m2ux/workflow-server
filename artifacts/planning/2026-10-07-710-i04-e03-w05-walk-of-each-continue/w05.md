# W05 — Walk of Each Continue-Batch Path

## Overview

Continue-batch can come back three ways that do not carry the held identity forward: the worker ends before yielding, the advance refuses the context, or the return is not an accepted result. Each of those leaves the identity held and mints nothing. This task is the walk that runs all three, so a later edit that mints a worker on the way through fails a run.

## Problem

- **The continuation always takes an envelope.**
  [The continue step](https://github.com/m2ux/workflow-server/blob/fbb9943f1da5f669f0bd3eb4265637edcf3365ed/tests/batch-loop-walk.test.ts#L113-L122) reads the next scripted envelope. A refusal puts that envelope back, and a `none` discards it. Neither is a call that returned nothing.
- **The missing return is not walked.**
  [A refusal](https://github.com/m2ux/workflow-server/blob/fbb9943f1da5f669f0bd3eb4265637edcf3365ed/tests/batch-loop-walk.test.ts#L578-L602) and [a failed continuation](https://github.com/m2ux/workflow-server/blob/fbb9943f1da5f669f0bd3eb4265637edcf3365ed/tests/batch-loop-walk.test.ts#L605-L619) each assert the identities a later dispatch wrote. [The worker ending](https://github.com/m2ux/workflow-server/blob/9511343c/corpus/meta/techniques/workflow-engine/continue-batch.md#L66-L69) is not one of those walks.

## Proposal

The walk scripts three returns from one continuation. The identity that enters that step is the identity that leaves it.

- **A missing envelope is not a result.**
  The worker ended before yielding. The step records that the continuation did not hold, leaves the result unset, and leaves the following envelope for the dispatch.
- **A refusal stops before a result.**
  The advance found no room for the held context. The envelope is put back for the dispatch, and the result is left unset. The identity is unchanged.
- **A failed continue is not an accepted result.**
  What came back is neither tagged result. It is discarded, the result is left unset, and the identity is unchanged.
- **None of the three mints.**
  The identities the walk records are the opening dispatch and the dispatch after the release. Nothing is written between them.
