# Displacement Named, the Serving Bind Recorded — October 2026

> Task · Created 2026-10-09

## Executive Summary

One experiment sidecar serves every session that walks a specimen, and its corpus bind is a single container-wide setting. A reload moves that bind without saying what it displaces, and a walk cites the corpus pin from the reload that preceded it rather than from the response that served it. A bind taken by a concurrent session therefore leaves no trace: the walk returns plausible output against another unit's corpus and reads as a pass.

This work makes the taken bind visible. A reload that would rebind an instance serving another corpus names that corpus and the sessions standing on it before it moves, and a walk record cites the pin the serving instance reported on that walk. It carries AC2 and AC3 of the epic, and W02 — an instance per dispatched unit — depends on it.
