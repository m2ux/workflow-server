## Overview

A check that reports a declared input whose description states an absent-value fallback while the declaration itself carries no `default` component, and the corpus edits that bring the tree it grades to zero. The signal is narrow enough to key on directly: inside a `## Inputs` entry, prose naming the value the input takes when the caller binds nothing.

## Problem

- **The fallback has a description and no home.**
  `features` read ["Optional `--features` flags (empty string when none)"](https://github.com/m2ux/workflow-server/blob/4330ef70~1/meta/techniques/cargo-operations/TECHNIQUE.md#L16) with no default on the declaration. A caller that binds nothing gets nothing; the operation interpolates an unbound value and carries on with a gap where the default belonged.
- **Nothing fails loudly.**
  No loader error, no guard, no refused call. The audit corrected inputs of this kind by hand across two passes, which is the only reason the class is known at all.
- **The same defect is already visible from the other side.**
  One correction closed a suppression in the binding-fidelity ledger: the input that had no producer now declares a default.
- **The tree carries the debt today.**
  14 inputs across 9 files state a default in prose with no `default` component — `start_session`'s three parameters, three `agent_technique` declarations, `list_query` in both GitHub listings, and five more.

## Proposal

Every `## Inputs` entry in every technique the corpus holds is read, the `default` component is looked for, and the description is read for prose naming the value the input takes in the absence of a binding. The corpus half declares the 14 defaults the prose was standing in for and cuts each sentence back to what the value holds.

- **Two families of signal.**
  A default stated in so many words — `defaults to`, `falls back to`, `default: X`, ``default `X` ``, or a dash-led `— default X.` ending the description. And a value paired with a clause saying no value arrives: "empty string when none".
- **The absence is of the binding, not of the world.**
  "Empty when none remain open" and "Empty when no graph covers the checkout" describe the value a producer yields in a state of the world — the input is bound, to an empty one — and no default can carry that. The marker has to close its clause, which is what separates "when none" from "when none remain open".
- **A value is written as a value.**
  In backticks, after a colon, after "to", or set off by a dash. "The repository's default branch" and "the PR base / default branch" name a branch, and the adjectival sense is left alone.
- **An absent value is not a fallback.**
  "Unset where the advance retires no activity" names no value, so there is nothing for a default to carry. It is the optionality statement an optional input owes its callers, and is passed over.
- **The corpus half lands first.**
  The check grades the `workflows` lineage, so the declarations are delivered to `i04/workflows` and the check to `i04/main` behind them.
