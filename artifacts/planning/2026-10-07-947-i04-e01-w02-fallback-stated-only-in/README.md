# Fallback Stated Only in Prose — October 2026

> Work item · Created 2026-10-07

## Executive Summary

A technique can state a fallback in prose — what happens when a value is absent, when a call fails, when a path is not taken — without any declaration behind it. The prose promises a route the contract never offers, and the run discovers the gap by improvising.

This work delivers the check that holds every stated fallback to a declaration, and the declarations the corpus owes it. It reports nothing against the corpus it grades and reports each corrected input at the commit preceding its correction, so a check that passes by looking at nothing is caught here.
